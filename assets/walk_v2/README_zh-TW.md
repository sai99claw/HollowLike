# 主角步行與腳步聲 v2（試作美術交付）

日期：2026-10-22。延續目前灰藍鴿子、靛色圍巾及粉紅腳爪造型，參考空洞騎士／絲之歌的手繪墨線與低飽和色調。由內建圖片生成重畫並修正一次；不是把舊四幀淡化混合或加殘影。

## 播放與落腳事件

0～11 循環，不重複首幀。預設 20 fps、每輪 0.6 秒；可依實際移動速度調整。00、06 是設計上的落腳事件，間隔 0.3 秒。單步音檔開頭保留 4 ms 防爆音，遊戲觸發時直接播放即可。主檔 pivot 固定 [164,224]；runtime80 固定 [51.25,70]。朝右，朝左由程式鏡像，鏡像必須以 pivot 為中心。

切圖時保持統一比例，將可見腳底放到共同基準線；每張使用同一 pivot，不再依當幀的左右腳位置重新估算水平中心。沒有動作補間或淡化混幀。身體、圍巾仍有生成圖的小幅形狀差異，這是供本輪試播評估的新素材，尚未經使用者確認為最終動畫。

## 交接給遊戲整合者

此包是美術與音效交付，**尚未替換或部署現行遊戲**。既有程式與 manifest 需要一起調整，否則只換圖片無法改善播放：

1. `scripts/sprite_art.gd` 的 run 分支目前是 `int(time*10)%4`，需改為依新的片段幀數／fps 選取，不能繼續只取 4 幀。`assets/illustrated/manifest.json` 的原 `pigeon_walk` 也只有 4 筆資料。
2. 本包 manifest 的路徑相對於 `res://assets/walk_v2/`；既有繪製器的 ROOT 為 `res://assets/illustrated/`，請新增讀取此根目錄的適配或整合正確相對路徑。不能直接把整份 manifest 蓋掉原檔，否則會遺失其他片段。
3. 只替換行走片段；待機、跳躍、攻擊、受傷等保留各自片段。此包不含新待機／跑步動作。
4. 動畫相位應在起走時重設，或由累計地面移動距離推進；停步、騰空、受擊、暫停與傳送均不得繼續發腳步聲。不要用全域時間硬切到任意姿勢。
5. 腳步事件在跨過 00／06 時觸發一次；以相位跨越計數，避免低 fps 漏播或同一幀重複播。每次隨機選同地表四個 WAV，避免連續同一個；可用約 ±3% pitch 變化。
6. 目前移動常數 330 像素／秒是快速移動；單一普通步行動作不可能在所有速度下自然不滑步。請在遊戲中按地面速度調整週期，並評估高速時是否另做跑步。此交付只提供目前要求的步行試作。

## 既有不順的可確認原因

原走路四幀的貼圖高度為 51／44／51／50；腳底 pivot 的 x 為 39.5／37／45.75／21.25，且程式用全域時間每秒 10 幀循環。這些數值容易造成身體在切幀時橫向跳動與姿勢突變。本包修正圖像定位並增加動作幀數；遊戲端播放仍需依上列接入。
