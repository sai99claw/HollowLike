# 枝間鴿行 · Pigeon Tower

Godot 4.7.2 / GDScript 的 2D 動作遊戲原型。以原生 Godot 專案作為多平台開發基礎，附 Web 匯出版。這是可擴充的玩法垂直切片，並非完成版商品。

[線上遊玩](https://pigeon-tree-tower.franksaioffice.chatgpt.site/) · [版本更新紀錄](RELEASE_NOTES.md)

## 開始

以 Godot 4.7.2 開啟 `project.godot`，按 F6 / F5 執行。採 Compatibility renderer，不需要第三方外掛。Web 版本需要 HTTPS、WebGL 2 與支援 WebAssembly 的現代瀏覽器；引擎下載約 10 MB，解壓後約 40 MB，遊戲資源另行載入。

在鳥巢用方向鍵走向標有「無雙夢境」或「新手教學」的門。肉鴿入口在上方，需下砍蘑菇反彈，再二段跳抵達。靠近站點後地燈亮起，此時按 ↑ 互動，房間之間直接穿門通行。

| 動作 | 鍵盤 |
| --- | --- |
| 移動、攻擊方向 | 方向鍵 |
| 跳躍、二段跳、滑翔 | Space，下降時按住可滑翔 |
| 衝刺、按住跑步、0.5秒內再按穿刺 | C |
| 普攻、按住集氣後放開 | X |
| 副武器 | Z |
| 切換已持有副武器 | Q |
| 長按回血 | A |
| 站點互動、裝備面板 | ↑、E |
| 背包、符文盤、技能樹 | I、R、K |
| 地圖 | 按住 Tab 暫看、M 固定，左右切換，Esc 關閉 |
| 設定 | Esc |
| 主武器；冒險中用消耗品 | 固定羽毛刀；1～5 |
| 選單選擇、確認、關閉 | 方向鍵、攻擊鍵／E、Esc |

手把支援基本動作；設定中可開觸控按鈕。手機排版、手把完整導覽及原生輸出仍需裝置驗證。Esc 設定可自訂鍵位及鏡頭縮放（預設 1.3×，範圍 0.8–2.0×），兩者自動保存。「畫面與聲音」的放大填滿採 16:9 置中裁切，可輸入 1.00～2.00 的額外放大倍率。WASD 不預設方向操作；A 為回血。設定有「練習：全技能」、慢速三階段與判定框，便於驗收技能。技能也能透過低門檻的冒險次數／推進解鎖。

## 已實作範圍

- 兩種模式、鳥巢入口、整備房、羽毛刀、翅膀普攻與集氣大刀動作、副武器背包。
- 六張依序生成且共享全域座標的塔式地圖、外緣 Boss 與下一圖銜接、每圖 20% 獎勵房判定、依高度變化背景。
- 二段跳、貼牆視同落地、牆跳、雙衝、方向集氣、衝刺集氣、向下穿刺落地範圍傷害。
- 共用攻擊前搖／打擊期／後搖時鐘，對應動畫姿態；拼刀、擋彈、受擊、掉落光效、音效與粒子。
- 無雙局內累積強化；Roguelike 固定基礎傷害、符文與副武器收藏、消耗品手動使用。
- 16 格符文盤、永久收藏、整備取用舊符文、金幣造型商店、副武器合成、一次復活。
- 本機存檔。Web 存檔依賴瀏覽器站點資料，尚無跨裝置雲端同步。

## 檔案分工與調參

- `scripts/main.gd`：主迴圈、移動／戰鬥判定、房間狀態、存檔與模式規則。
- `scripts/attack_state.gd`：共用三階段時鐘與每次攻擊命中去重。技能字典的 `windup`、`active`、`recovery` 各自可調。
- `scripts/game_data.gd`：主副武器、敵人、道具、符文與技能表。
- `scripts/tower.gd`：可重現種子的六圖生成與全域鄰接。
- `scripts/art.gd`：可縮放向量角色、各階段姿態、環境與入口造型。
- `scripts/game_ui.gd`：HUD、背包、符文盤、技能樹、整備與設定。
- `docs/game-mechanics.md`：玩法規格；其中「待定」不代表已獲定案。

目前僅羽毛刀可獨立裝備。普攻由左右翅交替，並有上揮和下踢；集氣釋放保留原大刀迴旋斬。v0.5 驗收表中的三武器選擇為歷史規格。符文效果、同類加成、合成配方、敵人／Boss 數值、復活保留規則等尚未定案，目前使用可替換的暫定值。復活暫採整次冒險一次、回目前圖初始房；選單暫停戰鬥。敵人原型與美術是驗證玩法用，尚未達量產內容／動畫品質。

## 驗證

```sh
python3 scripts/verify.py --godot /path/to/godot
```

各組測試使用獨立存檔。

## 匯出

安裝 Godot 相符的 export templates：

```sh
python3 scripts/build_web.py --godot /path/to/godot --data-home /path/to/data
```

模板安裝在 `data-home` 底下的 `godot/export_templates/4.7.2.stable/`。建置會驗證匯出的 PCK 後分片。Web 使用單執行緒，避免要求 cross-origin isolation。`web_shell.html` 與 `prepare_web.py` 將引擎切為小於靜態主機單檔限制的區塊，載入時重組 WASM。請將整個 `dist/` 部署至 HTTPS，不能只開啟 `index.html` 本機檔案。修改原始碼後須重新匯出。

附 Linux／Windows 匯出預設，未交付已測試的原生執行檔。Android／iOS／macOS 後續須在對應工具鏈設定簽章、觸控、安全區與商店要求，並測試裝置效能。
