# 枝間鴿行 · Pigeon Tower

Godot 4.7.2 / GDScript 的 2D 動作遊戲原型。以原生 Godot 專案作為多平台開發基礎，附 Web 匯出版。這是可擴充的玩法垂直切片，並非完成版商品。

## v0.45 首頁音樂與塔內場景

## v0.44 戰鬥效能修正

## v0.43 網頁輸出解析度修正

[線上遊玩](https://pigeon-tree-tower.franksaioffice.chatgpt.site/)。網頁版的 WebGL 輸出緩衝區固定為 1280×720。瀏覽器以 16:9 等比放大畫面，高 DPI 螢幕的輸出像素數維持固定。效能紀錄可核對 `webgl_buffer_px` 與幀間隔。

## v0.42 可貼回的效能紀錄

遊戲右下角「效能紀錄」→「開始錄製」。在空房停留約 10 秒，再走動／換房，總共玩 30～60 秒；卡頓時按「標記卡頓」，最後按「停止並顯示報告」→「複製整份報告」，直接貼回聊天，也可下載 TXT。最長 120 秒自動停止；完成報告只保存在本機，不自動上傳。開啟報告會暫停遊戲，關閉後繼續。

包含實際幀間隔百分位、CPU 各段時間、繪圖呼叫與物件／粒子數、房間、瀏覽器、WebGL 與解析度；GPU 毫秒未直接量測。詳見 [v42-performance-log.md](docs/v42-performance-log.md)。

## 開始

以 Godot 4.7.2 開啟 `project.godot`，按 F6 / F5 執行。採 Compatibility renderer，不需要第三方外掛。Web 版本需要 HTTPS、WebGL 2 與支援 WebAssembly 的現代瀏覽器；引擎約40MB，遊戲資源另載入。

入口左側起飛鴿子是無雙，右側戰士鴿子是 Roguelike。可直接點門，或走近後按上方向鍵。初始房走到各站點前按 E／攻擊鍵操作；房間的門直接穿過通行，不需按鍵。

| 動作 | 鍵盤 |
| --- | --- |
| 移動、攻擊方向 | 方向鍵 |
| 跳躍、二段跳 | Space |
| 衝刺、按住跑步、0.5秒內再按穿刺 | C |
| 普攻、按住集氣後放開 | X |
| 副武器 | Z |
| 切換已持有副武器 | Q |
| 長按回血 | A |
| 互動 | E / 攻擊鍵；過門直接穿過 |
| 背包、符文盤、技能樹 | I、R、K |
| 按住查看小地圖、設定 | Tab（放開隱藏）、Esc |
| 主武器；冒險中用消耗品 | 固定羽毛刀；Shift+1–9 |
| 選單選擇、確認、關閉 | 方向鍵、攻擊鍵／E、Esc |

手把支援基本動作；設定中可開觸控按鈕。手機排版、手把完整導覽及原生輸出仍需裝置驗證。Esc 設定可自訂鍵位及鏡頭縮放（預設 1.3×，範圍 0.8–2.0×），兩者自動保存。WASD 不預設方向操作；A 為回血。設定有「練習：全技能」、慢速三階段與判定框，便於驗收技能。技能也能透過低門檻的冒險次數／推進解鎖。

## 檔案分工與調參

- `scripts/main.gd`：主迴圈、移動／戰鬥判定、房間狀態、存檔與模式規則。
- `scripts/attack_state.gd`：共用三階段時鐘與每次攻擊命中去重。技能字典的 `windup`、`active`、`recovery` 各自可調。
- `scripts/game_data.gd`：主副武器、敵人、道具、符文與技能表。
- `scripts/tower.gd`：可重現種子的六圖生成與全域鄰接。
- `scripts/art.gd`：可縮放向量角色、各階段姿態、環境與入口造型。
- `scripts/game_ui.gd`：HUD、背包、符文盤、技能樹、整備與設定。

## 匯出

安裝 Godot 相符的 export templates：

```sh
godot --headless --path . --export-release Web dist/index.html
python3 scripts/prepare_web.py
```

Web 使用單執行緒，避免要求 cross-origin isolation。`web_shell.html` 與 `prepare_web.py` 將引擎切為小於靜態主機單檔限制的區塊，載入時重組 WASM。請將整個 `dist/` 部署至 HTTPS，不能只開啟 `index.html` 本機檔案。修改原始碼後須重新匯出。

附 Linux／Windows 匯出預設，未交付已測試的原生執行檔。Android／iOS／macOS 後續須在對應工具鏈設定簽章、觸控、安全區與商店要求，並測試裝置效能。
