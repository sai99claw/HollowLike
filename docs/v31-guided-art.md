# v31 guided projectile animation art

Generated with the builtin imagegen tool. These are two separately generated true-RGBA eight-frame atlases, copied into the project without raster transformations. The discarded first missile atlas was rejected because its bottom-row noses pointed left; a targeted imagegen correction fixed all eight noses to point right.

## Runtime contract

- Files: `assets/v31/projectiles/needle.png` and `homing_missile.png`, each accompanied by JSON metadata and lossless1024px import settings.
- Original images are1774×887. Four-column/two-row cell boundaries are rounded to integer source pixels; use the per-frame `rect`, not integer division of the nominal443.5px cell size.
- `pivot` is LOCAL to each `rect`. It follows the fuselage rather than the changing rear-fin bounding box. Use a single style scale derived from `max_body_extent` (375needle,369missile) for all eight frames, so rolling poses do not pulse in size.
- Needle is a clockwise axial-roll sequence; homing missile is counterclockwise bank/roll. Their noses remain right in every frame; rotate the overall atlas frame only to follow flight heading, never tumble them like bombs.
- Runtime frame2 and6 use small rear-fin smears. Other frames remain sharp. Needle source cell order is0,1,2,3,4,6,5,7 so its two smear images appear at the requested timing. Missile order is0..7.
- Each atlas contains eight different pixel hashes. RGBA alpha was verified with more than50% fully transparent pixels, and every frame has nonempty visible bounds. No environment, glow backing, trajectory or dust was baked in.
- Simplified metal/feather silhouettes, restrained turquoise or blue accents and ivory edge highlights follow the attached article's silhouette-first approach.
