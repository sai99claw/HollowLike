# v0.5 缺圖交接清單

使用者分工：本專案只整合與驗證，所有新圖交由使用者指定的其他 agent 製作。未交付的新圖不得標記完成。下表為建議最低製作幀數；鏡像／旋轉可共用，不必重畫同一招的左右方向。

## 共通交付規格

- 透明 RGBA PNG；不加背景、棋盤、格線、標題、文字、光暈底板。
- 最佳交付為逐幀 PNG＋一張預覽圖；若用圖集，固定等格、每格四周至少32px透明安全間距，不可跨格。
- 同一角色動作固定畫布、相同比例與腳底pivot；攻擊特效與角色、武器分開。特效用中心／發射點pivot，附JSON說明。
- 畫面朝右；左向由程式鏡像。角色建議256×256，攻擊／死亡512×512，大範圍特效768×768；實際顯示由程式縮放。
- 動畫幀應是連續動作，不要用淡入淡出混幀／殘影補幀。長達1.5秒的攻擊採12fps左右的循環段，不把少量幀硬拉成慢動作。
- 三階段分別標示windup／active／recovery。角色姿勢決定觀感，實際命中由程式時鐘控制。
- 命名格式 `<biome>/<object>/<clip>_00.png`。通用生態用`common`。請同時提供裁切尺寸與pivot、循環起訖幀。遊戲接收`manifest.json`中的`animations[clip].frames[] = {path,pivot:[x,y],size:[w,h]}`；循環段附`fps:12, loop_start:2, loop_end:7`等零起算索引。
