# v0.33 遊戲與場景更新

## 玩法

- 投射物以v32人物高度1/4規格為來源，長寬各×1.5，因此面積×2.25；基準最長邊19.1015625世界像素（標準人物高50.9375的3/8）。原本符文每枚尺寸+5%保留。
- 六關各獨立擲一次50%商店；未出現時原位置為戰鬥房。RD新增商店機率參數，預設0.5。
- 移除生成器的專用泉水房。每張戰鬥房／菁英房各自10%機率放置小泉水，地形與敵人仍保留。RD泉水參數改為fountain_chance預設0.1，舊spring_chance設定不再控制新內容。
- 小泉水採地面支點、完整物件與保留區配置；附近恢復生命與能量。受擊只噴出原生水滴粒子，不再建立水花貼圖動畫或泛用命中光效；單次18滴、0.72秒，最多12組。
- 展示台武器具有固定錨點，不受重力、物件碰撞、磁吸或接近自動拾取影響。↑／攻擊確認仍可領取，普通掉落維持原物理。
- 整備房更名安全屋。原皮膚換裝功能保留在安全屋，首頁的換裝站已移除。
- 首頁共用實際移動控制器，允許跑步、二段跳、攀牆、單／雙C、下CC與落地行為；首頁解鎖僅為移動試用，不改永久技能進度。彈跳莢碰觸即向上彈射。
- 首頁、新局與死亡重開的初始主武器統一羽毛刀。冒險紀錄改為獨立書台站點，可近身↑／攻擊確認。

## 美術

共新增13張PNG原畫：三生態泉水3張、安全屋背景3張、安全屋站點圖集3張（18件）、首頁背景／前景枝葉／四件道具／粒子葉片4張。

- 生態主色：天空藍白石雕、樹幹翡翠根木、地下琥珀玄武岩。
- 安全屋六站共用功能輪廓：急救神龕、鐵砧鍛造、三孔重鑄、寶箱倉庫、能量晶座、披風架。
- 首頁採手繪哥德樹冠場景與獨立枝葉景層，重畫無雙／肉鴿門、冒險紀錄書台、彈跳莢；黑白羽毛與前後景飄葉皆為受控數量原生粒子，離開首頁停止模擬。
- 原始PNG保留未修改；來源像素錨點與alpha bounds見相鄰JSON。安全屋站點最終匯入896px，泉水512px；首頁背景／道具1024、枝葉512。
- 已退休的舊首頁背景／兩扇門及水花圖集保留於原始碼，從正式匯出排除。

精確提示詞、來源與檢查見v33-home-art.md、v33-safehouse-art.md、v33-spring-art.md。

房型／機率需重新開始一局；倉庫與共用意見資料保留。
