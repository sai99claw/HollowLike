# v0.37 — 水池、視差、戰鬥回饋與動作節奏

本版完成使用者本輪行為與美術修改，延續公開v0.36的十五種普通怪及六種菁英。

- 三生態泉水恢復真正的入水區域；浸泡回生命／能量、減速，池沿置於角色之前。保留三種既有生態池體，放大至240世界單位；貼圖分層依實際匯入尺寸換算，水面採橢圓薄層，避免矩形水色蓋住池體。攻擊只濺原生水滴粒子。
- 中景物件由前景變換改為獨立0.42視差；背景0.10、前景1.0。安全屋背景同樣分層。以進房鏡頭重設中景原點，避免高房間的物件因新視差整批沉到畫面外。完整物件仍保留自己的腳底錨點。移除先前要求取消的安全屋鳥巢；首頁鳥巢保留。
- 敵人命中移除原地受擊特效與本體殘影，改三幀手繪碎羽向攻擊反向噴出，帶繪製動態模糊；另以命中點為中心疊三幀亮色月牙。長軸固定約畫面寬1/3，角度在±0.24弧度內變化，縮放鏡頭不會改變其畫面尺寸。
- 首次生命歸零會原地倒下並以重傷狀態醒來；重傷降低最大生命、能量與移速，可回安全屋急救。同一局第二次歸零才死亡，重新生成新一局，倉庫保留。急救不會重置已用的重傷機會。
- 單C不給無敵；橫向／向下CC在前搖及攻擊期保護，保留向下CC落地後既有0.5秒保護。
- 十五種普通怪重畫180張：每隻六幀移動、兩幀前搖、兩幀打擊、兩幀收招。移動12fps；前搖0.6秒，最後張張力姿勢長停留；打擊本體與獨立攻擊特效分離。既有菁英雙招動畫及0.85秒預警保留。受擊以白閃、0.05–0.08秒頓幀與後推回饋。
- 屍體不再壓成0.48倍高度，保持活體固定比例，剛體旋轉倒下。接觸尺寸取自實際姿勢的輪廓；旋轉後依可見邊界貼地，避免半截埋入地板。致命一擊的方向沿用至屍體，以1.5倍原擊退量飛出。
- 移除門口漸層光柱、光圈與色塊，改密集有色粒子匯入門口；批次繪製避免新增大量獨立畫圖呼叫。
- 依角色42高碰撞框與牆的垂直交集計算：至少51%時吸牆，首次吸附維持一秒再下滑；不足51%且平台上方可容納角色時，四張手繪姿勢在0.32秒內攀上。兩側一致，低天花板時不穿牆。
- 落地重頓只於嚴格超過六格落差觸發，格寬取當前地圖tile_size；半秒蹲下與微震保留，一般跳躍及下CC不套用此停頓。
