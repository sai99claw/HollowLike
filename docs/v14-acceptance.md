# v0.14 衝刺、下衝及集氣修正

## 操作與戰鬥

- 單C保留鴿子本體，背後播放短促的6幀小噴射，不使用風化身圖。
- 雙C左右突進使用獨立8幀風化姿態；打擊期隱藏一般角色及手持武器，呈現完全化身為風。下衝沿同一風形旋轉，成形後循環中段風帶直到落地。不同全域速度下，特殊突進結束不再退回普通噴射。
- 下＋單C仍不前衝；下＋雙C全程無敵，包含0.035秒起手，途中使用每個物理子步的掃掠判定造成傷害，同一敵人穿越傷害只算一次。接觸第一個平台就停止，附近地面上方敵人再受一次落地衝擊。地面衝擊不打到平台下方的敵人。
- 接地後至少0.5秒無敵。無敵判定與下衝狀態相連，不靠短暫的0.28秒計時器；慢速設定超過原來的1.8秒攻擊時間，也能一直保持風形、傷害與無敵到接地。
- 集氣基準改2秒，已有縮短集氣的升級仍作用。釋放的完整動作固定1秒，包含原圖的起手、打擊、收尾，不再額外增加獨立前後搖。普通攻擊的前後搖及攻速規則維持原本設定。
- 釋放期間可水平移動、空中操控及跳躍；所有主武器都適用。集氣釋放不施加玩家反作用力，大刀釋放命中也不會額外定身。保留霸體及同一動作不可被其他出招替換的規則。
- 每目標集氣傷害仍至少相隔0.5秒，一秒內最多兩次。

## 動畫

三張獨立透明新圖分別含6、8、12張不同畫面。小噴射與風化身分開取圖、尺寸與錨點；落地依次出現接觸閃光、橫向風壓、捲起羽狀風帶、石屑、煙塵與消散。落地每幀固定0.9倍原圖像素比例，沒有把同一張圖片逐步放大。源區域在量測的地面接觸線裁切，世界座標底部固定在碰到的平台表面；額外碎屑在該表面上方消散。

六套既有集氣角色／招式動畫改成依釋放進度完整播放一次，從第一幀走到最後一幀，解除過去循環索引造成的提早截斷。按住集氣時仍維持原有循環，不影響蓄力粒子。

[製作提示及檔案路徑](art-direction-v14.md)、[26幀像素內容驗證](animation-assets-v14.json)。像素雜湊用於確認各來源區域不同，配合實際圖像檢視；不拿雜湊推論動畫觀感。
