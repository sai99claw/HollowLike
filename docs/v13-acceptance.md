# v0.13 變更與驗收

## 畫面與流程

- 初始畫面是樹梢上的家。五個獨立美術資產：晨光樹冠背景、巢、四格睡醒動作、金色羽翼無雙門、冷色厚重 Roguelike 門。先睡在巢中，方向輸入觸發醒來，再左右走入門開局；滑鼠點門與互動鍵仍可使用。遠行紀錄板移到巢旁。
- 商人房另有新繪完整背景與透明中景，保留三桌、六件商品、借用試打／歸還／購買流程。室內不播放戶外下雨或遠景飛鳥。
- 整備房、商人房、溫泉採1500×1120邊界及同一鏡頭縮放規則，角色不因進房而縮小；內部實際高度至少一個畫面。為同時保留相同角色比例與完整高度，固定安全房允許鏡頭跟隨移動，取代v0.12的整房縮放。
- 整備房有完整挑高，四個互動台均在二樓850高平台，一樓1050高放固定及漂浮假人。上門仍有普通跳躍可達路線。測試假人是84×120的真實敵人判定框：不會死、零接觸傷害、不攻擊，可累積實際武器傷害；命中不彈起、不施加反作用力。
- 普通中景的非碰撞平台物件移除額外的整層染色，保留原圖著色。

## 戰鬥

- 三主武器基準集氣3秒，蓄力升級仍可縮短；釋放有效期固定1秒，不受攻速影響。每目標兩次傷害，間隔至少0.5秒。結束邊界排除浮點誤差額外傷害。
- 下＋單C不前衝；雙C下衝由520逐步加速至1480終速，每秒加速2100，在碰到的第一個平台停止並重設速度。向上衝仍依舊版規格關閉。
- 普通衝刺、左右雙C及下衝使用同一新繪強風圖系統；壓縮亮心、風帶和長尾增加速度感。下砸圖像矩形完全在接觸面上方，碎屑碰到該平面即消散，保留白色接觸閃線。

## 效能

- 移除普通衝刺每個物理子步隨機建立粒子字典；改成固定數量圖像繪製。
- 精簡模式投射尾跡最多24個發射器、各5粒；先前最多160個各10粒。這是資源上限降低1600→120，並非FPS量測。
- 畫面外投射物不新增尾跡；預設環境／雨／羽毛粒子不再套額外模糊材質，保留失焦蜻蜓與遠景鳥的專用模糊。
- 主場景啟動只讀取一般圖集及Boss的描述資料，不預先解碼所有幀。閒置命中圖層不再持續重建繪製清單。
- 重建環境還原時損壞的單張匯入快取；原始PNG驗證完好。

## 怪物身份

見[逐物種稽核](monster-art-identity-v13.md)：修正菁英攻擊共用樹精身體、可愛蟲受擊／死亡回退甲蟲及其他異種缺圖備援。逐幀目視306張角色PNG，另外核對可愛蟲圖集裁切；307張來源PNG均鎖定SHA-256。雜湊只防素材內容被換掉，不拿來推論圖中物種。

## 驗證方式

`tests/test_v13.gd` 覆蓋首頁睡醒及實際走門、三房型三組鏡頭比例、上下樓互動隔離、兩種假人真實受擊／漂浮、2.99秒與3秒放開輸入、1秒結束邊界、加速下衝撞上層平台、貼地風壓／碎屑邊界、尾跡資源上限、精簡模式材質及中文字形。

保留並更新舊套件的規格斷言；600個地圖種子及32個安全房通道組合仍做可達性檢查。原始碼完整套件與實際匯出PCK的選定套件分開執行；WASM/PCK分塊檢查大小及SHA-256。瀏覽器GPU畫面、音效聽感、輸入手感及實機FPS尚未在此環境量測，不宣稱達到特定幀率。

本批結果：23／23個原始碼套件通過；實際匯出PCK的8／8個套件通過。WASM 39,514,754 bytes分3塊，PCK 92,434,896 bytes分7塊；重組大小與SHA-256驗證通過。`git diff --check`無空白錯誤。
