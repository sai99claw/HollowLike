# v0.28：衝刺距離、密集場景效能與高處落地

## 手感

- C與水平CC的移動距離相對v0.27縮短20%，持續時間與攻擊傷害不變。單C速度975→780、CC速度1410→1128；向下CC仍落地終止。
- 自由下降超過256世界像素才觸發重落地。先有0.04秒撞擊頓幀，再蹲伏約0.5秒，畫面輕晃；半秒內停止移動、跳躍、衝刺與攻擊，已按住的方向在結束後恢復，避免按鍵變成延遲攻擊。
- 新四幀蹲伏素材以共同體型比例、各幀腳底pivot繪製；壓縮→低蹲→保持→起身。普通跳躍落地、泡水、跳台反彈與主動下砸保留各自處理。
- 素材、精確生成提示與匯入資訊見 `v28-landing-art.md`。

## 效能

- 碰撞先依整段移動的身體範圍篩出附近障礙物，後續子步不再逐次掃描整個房間。若重疊地形或轉角校正讓身體移出預測範圍，改用完整舊式掃描重算，保留卡入地形的復原結果。
- 投射物射線先排除不在掃掠範圍的地形，再計算精確命中。
- 飛行避障保留原路徑與逃離方向，只對距離上限內的地形做反覆淨空檢查；飛行怪不再無謂查找腳下站立平台。
- 同幀重用怪物碰撞尺寸、仇恨判定與地形陣列；體型或物種改變會使尺寸快取失效。
- 角色繪圖使用本地座標與節點變換，移動及鏡頭不再觸發貼圖重建。走動姿勢至多30次／秒更新，攻擊階段與受擊閃白仍即時更新；開選單或頓幀時沿用凍結姿勢。
- 不為尚未出現於視窗的怪物建立繪圖節點，受擊回饋例外；死亡後釋放繪圖節點。
- 每個地圖轉角原64次小面片指令，合成一個快取mesh指令；保留相同64格、UV、頂點透明度與貼圖比例。沒有減少怪物數量或道具數量。

## 同機CPU基準

固定種子、80隻怪物、401個碰撞區塊，使用 `tests/benchmark_dense_v28.gd`，未啟用WebGL；以下是引擎CPU耗時，不是瀏覽器FPS。

| 項目 | v0.27 | v0.28 |
| --- | ---: | ---: |
| 怪物更新每次，中位數 |51.233ms|11.346ms|
| 單次身體碰撞 |163.30μs|67.27μs|
| 單次飛行轉向 |320.85μs|29.25μs|
| 靠牆飛行避障 |8713.92μs|365.42μs|
|80個轉角繪圖指令重建 |8.706ms|0.286ms|

此壓力場景的怪物更新CPU耗時降低約78%。實際玩家端FPS仍取決於瀏覽器、GPU、解析度與場景。
