# v0.36 生態怪物行為

三個先完成的美術設定檔 `assets/v36/monsters/*-brief.json` 同時作為行為與美術來源。十五種普通怪各有一種固定移動與一種固定攻擊；六張地圖各有唯一菁英，每種菁英兩招。普通前搖0.7秒、菁英0.85秒，均有有效期與收招。RD攻擊時間倍率仍可調整。

衝撞是一個完整AttackState動作：前搖鎖方向、有效期才移動和造成身體命中、撞牆立即收招，沒有另一個自動dash移動偷偷發動第二招。新版怪物待機身體重疊不再造成隱藏碰撞傷害。Boss原本的接觸傷害、姿態與階段規則保留。

實際房間生成依生態選五種普通角色，所有菁英（包含菁英房與Boss三守衛）依當前地圖選唯一菁英。地面菁英不再強迫以hover生成；飛行角色才使用空中放置。菁英既有血量三倍規則保留。練習房有28個項目：十五普通、六菁英、一可愛角色、六Boss；舊索引0–16維持原分類形狀以相容既有工具。

驗證：新增回歸檢查實際種子171完整塔出現十五普通、六地圖菁英與六Boss，地面支撐、固定大小、單一行為、兩招動畫索引、衝撞無前搖傷害、鎖方向、有效期命中及撞牆收招。另通過練習房v16、BossDirector v35、怪物移動v18、效能v28。

`test_ecology_contact.gd` 是舊版待機／冰凍身體接觸即受傷的規格，不適用新版有明確前搖的普通怪；本次未把它當成新版行為驗收。既有Armament.enemy工廠仍保留給舊測試與訓練假人，不再是一般戰鬥房生成來源。

匯出需包含brief JSON；渲染由整合者提供的monster_art_v36處理：actor以roster_id / roster_biome / roster_row / roster_elite辨識，attack以roster_attack區分兩招，visual_id / hazard_visual_id / melee_visual_id是獨立圖集鍵。此行為提交不含圖片生成或發布。

衝撞起手距離會依有效期、攻擊時間倍率、敵人攻速、移動速度倍率及雙方碰撞體寬度計算，保留16px收尾餘量；不是使用遠大於實際位移的名義射程。只有衝撞角色的接近停止距離改為36px，讓最低速度設定也能進入可觸發範圍。新增`test_ram_reach_v36.gd`以48次完整AI攻擊驗證兩種衝撞體型、左右方向、三種移動速度、兩種時間倍率及兩種攻速：在觸發邊界內能命中靜止目標、邊界外不會錯開衝撞，前搖仍無傷害且不追蹤轉向。
