# 1080p 顯示與首頁 RD 入口修正

## 已確認的原因

- v0.35 將 RD 美術室移至選單的開發工具，本次依使用者要求恢復首頁直接入口，保留練習房。
- 專案原本使用 1280×720 的 `viewport` 渲染模式；在 1920×1080 顯示時，整張完成的 720p 畫面才放大，因此 UI 字體、輪廓與所有貼圖都一起變軟。
- 首頁背景原圖為 1536×1024，匯入卻降至 1024×682；首頁框景降至 512×341，安全屋站點圖集降至 896px 寬。這些是匯入縮圖造成的額外細節損失。
- 主要 v22／v23 角色與地形圖集目前已沒有匯入縮圖。以 `action-walk.png` 為例，原圖與實際載入均為 1448×1086；本次沒有證據需要重新縮放其 source rectangles，因此未改動正確的圖集座標。

## 修改

- 預設原生視窗改為 1920×1080，使用 `canvas_items` 在實際輸出解析度繪製 2D 與文字。
- 保留 1280×720 邏輯座標、視野與移動手感。1080p 的畫布變換為 1.5 倍，畫面中心 `(960,540)` 逆映射仍為邏輯 `(640,360)`；UI 錨點及觸控空間不變。
- 首頁練習房與 RD 美術室置中並排，仍可從設定中的開發工具進入。
- 首頁、安全屋及鳥巢採用原圖尺寸；保留原始 PNG，不以放大縮圖假裝補出不存在的細節。
- 22 張場景貼圖採用匯入品質 0.95 的高品質有損壓縮。背景、框景與站點提高解析度，同時讓這組匯入資源由 23,830,666 bytes 降至 10,436,412 bytes，淨省約 12.77 MiB，為新怪物圖集保留發布空間。沒有刪除 runtime 素材。

## 驗證

- `test_display_hd_v36.gd`、`test_review_ui_v35.gd`、`test_v17.gd`、`test_grounded_art_v34.gd`：4／4 通過。
- 使用 X11／Mesa llvmpipe 實際執行 HD 測試：確認 framebuffer 為 1920×1080，邏輯視口與 UI 根節點維持 1280×720，實際點擊 RD 按鈕可開啟美術室。
- 原生渲染對照：舊 `viewport` 輸出影像為 1280×720，新 `canvas_items` 為 1920×1080。檢查首頁與安全屋畫面，按鈕、文字、站點及前景位置正確。

1080p 渲染不會憑空增加原圖的細節；部分背景原圖最高仍是 1536×1024。遠／中景的景深效果也仍保留。這次修正的是全畫面先降成 720p 再放大，以及部分場景額外縮圖；軟體渲染不作真機 FPS 結論。
