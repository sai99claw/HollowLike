# v0.18 操作與攻擊回饋

本次以乾脆、可預測的操作為目標，保留原本的走路圖、轉身圖、腳步同步與死亡羽化。

| 操作 | v0.18 行為 |
|---|---|
| 左右移動 | 第一個物理子步直接達到目標速度；放開即停，反向即轉。地面與空中相同。 |
| 跳躍 | 上升重力 1250；下落 2500，落速上限 1000。放開跳躍鍵的當幀將上升速度限制為 140。 |
| 普攻 | 按下 X 立即開始判定；放開不再補一刀。忙碌或受傷時的無效點擊直接丟棄。 |
| 集氣 | 普攻後繼續按住 X 可集氣；2 秒後放開，完整施放 1 秒。已就緒的集氣可取代普通後搖。 |
| 攻擊節奏 | 普攻前搖歸零，判定期為腳爪 0.09 秒／羽毛刀 0.12 秒／大刀 0.16 秒；原總週期轉移至可移動、可取消的後搖。攻速符文縮短後搖。 |
| 動作取消 | C 可取消前後搖；空中按下方向加新一次攻擊，可用下劈取消後搖。大刀僅在短暫打擊期停步。 |
| 下劈反彈 | 空中命中普通敵人或明確標記的反彈機關，立即向上彈跳，恢復空中衝刺與二段跳。訓練假人維持不反彈。 |
| 命中停頓 | 腳爪 3 幀、羽毛刀 4 幀、大刀 5 幀（以 60 Hz 計）；同步停止世界時鐘、物理、動作與戰鬥粒子。 |
| 受擊白閃 | 每隻怪物獨立 alpha 輪廓材質；白閃姿勢隨命中停頓保持，恢復後約一幀消退。普通狀態回到預設材質。 |
| 聲光 | 獨立月牙刀光、定向橘白碎屑，以及重新合成的金屬命中音；揮空仍使用原本風切音。 |
| 空中姿態 | 上升／頂點／下落各自保持清楚姿勢；落地有 0.09 秒輕微壓縮，碰撞框不縮放。 |

怪物移動新增 12 張獨立透明圖集，涵蓋五種普通怪、可愛遊盪者與六種 Boss；菁英沿用自己的物種。共 96 個新畫姿態，攻擊、受傷及死亡維持各物種自己的來源。RD 美術室可搜尋「八幀移動」與「白色羽刃月牙」逐幀查看。

主要程式：`player_motion_v18.gd`、`main.gd`、`enemy_canvas_v18.gd`、`slash_art_v18.gd`、`monster_motion_v18.gd`。美術保存在 `assets/v18/`，使用內建 imagegen 生成；完整提示詞見同目錄 `slash-prompts.json` 與 `monster-motion-prompts.json`。

驗證包含實際輸入當幀命中、跳躍高度、非對稱重力、同步凍結、無效點擊丟棄、兩秒集氣、下劈反彈與取消、96 幀來源／物種對應，以及全塔跳躍可達性。瀏覽器 GPU 體感與 FPS 需要在支援 WebGL 2 的裝置上確認。
