# v0.24：兵裝、鍛造、菁英戰與生態地形

## 操作與角色

- 判定上牆後停留1秒，再以36世界像素／秒下滑。計時屬於物理攀附狀態，持續按住牆方向不會重設；離牆或落地後清除。
- 保留上升與頂點不自動攀附、C直接衝牆立即攀附、碰撞框側邊與雙腳接觸點對齊的規則。
- 所有站點按↑使用；救護站立即解除重傷並補滿生命、能量。
- E開啟主武器狀態，左依序切換附武器、消耗品、符文；右反向循環。R直達符文。頁籤可點擊，↑↓選擇，X確認，Esc關閉。主武器在狀態面板可直接切換。
- 面板放大武器原畫，附武器清單顯示裝備、無雙齊射序號或Roguelike重複強化度。沿用完整16格／3格符文盤。

## 九種附武器

| ID | 效果 |
|---|---|
| needle | 直線射擊 |
| chain_staff | 閃電連鎖 |
| impact_bomb | 拋物線＋爆炸 |
| ricochet | 直線射擊＋反彈 |
| homing_missile | 有限轉向速度的簡易追蹤飛彈 |
| trap_pod | 拋物線＋落地安置陷阱 |
| moonblade | 飛行斬擊 |
| fire_flask | 拋物線＋地板持續燃燒 |
| piercing_laser | 貫穿雷射，受實心地形阻擋 |

- 九種武器與九種對應投射物均有新透明PNG。投射物基準尺寸增加至原本兩倍，斬擊使用更寬的獨立判定。
- 新掉落、免費武器、商店與練習房只從這九種武器選取；舊武器定義保留，供舊儲藏資料相容。
- Roguelike重複拾取同ID武器增加1發，不另占清單，最高+8；達上限不再增加。
- 無雙改為武器掉落，最多16個武器實例。按一次Z保存整組齊射快照，消耗1格能量，在同一個出招時刻依序發動所有效果；不需切換。
- 新增疾矢（速度+15%）、遠星（射程+15%）、熾羽（傷害+15%）、盛羽（投射物與爆炸範圍+15%）四種獨立符文與原畫。屬性強化由符文提供。
- 蜜蜂每隻每秒攻擊一次；每枚蜂群符文提供1隻，每條同種正交連線再加1隻。大符文蜜使另外提供1隻。

## 永久藍圖與重鑄

- 正式取得武器即解鎖永久藍圖，保存於現有玩家檔；免費試用不計取得。既有家中武器載入時會補登對應藍圖。
- 整備房新增藍圖鍛造台，使用30金幣合成，優先扣隨身金幣，不足部分使用家中金幣。容量或+8已滿時不扣費。
- 整備房新增符文重鑄台，自選3枚隨身符文；可重複選擇同種，但不得超過持有數。消耗材料後隨機給1枚不同於材料的符文。
- 材料若穿戴中，先卸除超出剩餘持有數的格子；新符文有對應空槽即自動裝備。大符文包含在隨機池，結果仍受裝備槽限制。
- 新站點先使用既有整備原畫作底座，配獨立名稱與操作面板。

## 房間與獎勵

- 依生成順序，每完整5間非安全戰鬥房隨機挑1間菁英房；保留原探索地形，所有戰鬥敵人改為菁英。
- 清除菁英房後產生1個獎勵寶箱，必定含1枚大符文，另有一般金幣與消耗品。
- 六個Boss房各增加3名菁英守衛。Boss與守衛全部擊敗才打開通往下一關的側門。
- 區域圖與全塔圖新增菁英房的「菁」標記與橘色房框。
- 房型變更需要新冒險；原有永久收藏、鍵位與設定延續。

## 三生態美術與渲染

- 三生態重畫地形材質、1／2／3／4格平台、各2個完整中景物件，另新增各自的內凹／外凸自然轉角。
- 手繪哥德式暗黑奇幻，天空青藍、樹幹翠綠、地底琥珀紫；較高彩度但保留克制主色。
- 全系列固定2來源像素／世界像素。平台分別取用各長度的原畫，保留左右端部、取樣／重複中央至精確長度，沒有整張水平拉伸。
- 高解析既有邊緣裝飾採固定世界尺寸下採樣至共同來源密度，保留透明度與原始支點；不依實例任意縮放。
- 實心地形任意矩形（含1×2窄塊）先填滿底色，再使用連續世界座標取樣，避免無貼圖的灰塊與相鄰區塊UV接縫。
- 自然轉角只由實心方塊聯集的真實內凹／外凸角決定。轉角覆蓋採固定來源比例與局部透明羽化，避免直線裁切邊。
- 取消舊v21邊緣列中的混用裝飾與舊整片近景圖。邊緣裝飾向地形內嵌10px；高於42世界像素的裝飾放在互動前景之下，其餘放在其上。
- 中景使用完整獨立物件的暗色半透明版本，不裁掉物件輪廓。生態微粒新增不同方向、速度、顏色與風擺，精簡特效模式仍保留部分微粒。
- RD圖庫加入新素材及可複製ID；舊地形／平台渲染路徑保留檔案並標記un-used。
