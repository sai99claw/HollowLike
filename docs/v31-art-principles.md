# 從附文採用的美術原則

依使用者提供的〈The Secret Behind Hollow Knight’s Art Style!〉逐字稿分析（影片75qicQmgxKo）。以下是對文章的解讀與本遊戲的應用，不代表原作開發者的官方製作規範。

1. 輪廓與形狀語言先於細節：鴿子的圓潤主形保留親和感；刀刃用尖銳月牙、瓶罐用明確容器輪廓。這次七種實體投射物各用可辨識外形，避免縮小後只剩同一顆光球。
2. 分離可玩層與裝飾層：文章把近景深色、遠景淺色及模糊視為深度線索。應用時，裝飾可以低對比，可互動地形與危險投射物仍需清楚；不把整個前景壓成黑色。
3. 克制的生態主色＋小面積對比色：地圖主色統一，玩家與危險物以受控對比突出。這次投射物各保留原武器色系，灰塵低飽和，不能與本體搶亮度。
4. 線條與明暗分工：清楚外輪廓、簡化內部材質；金屬用少量冷暖高光，不用大量細碎刻線。以實際遊戲尺寸檢視，放大好看不能取代縮小可讀。
5. 動態模糊需要選擇：文章談的是場景深度模糊；本次把「保留主體清楚」延伸成旋轉動畫策略。八幀中大部分保持清晰，只在少數快速過渡幀用短弧形 smear；不讓整段動畫永久霧化。
6. 分層製作方便調整：每種投射物保留獨立圖集、旋轉設定與粒子層。美術幀不決定物理軌跡、傷害或碰撞。

這次直接落實1、3、4、5、6到投射物重製；2作為既有地圖後續檢查準則，沒有擴大本次範圍重畫整張地圖。
