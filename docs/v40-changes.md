# v0.40 效能與戰鬥回饋

## 最新規格

- 單 C 期間的大刀攻擊、雙 C 水平穿刺與下砸取消後搖。完整前搖／打擊期保留；集氣維持完整 1 秒打擊與零後搖。羽毛刀一般攻擊節奏不變。
- 單 C 成功啟動時只建立一次粒子爆發，採用二段跳同款羽毛貼圖、數量、大小、散角與淡出；方向朝衝刺後方。↓C 僅預備，沒有假衝刺或粒子。第二下 C 不重複建立單 C 粒子。
- 大月牙在局部座標左右鏡像，保留敵人實際貼圖中心、長度與隨機角度。碎羽沿攻擊方向從同一貼圖中心開始播放，取代 v38/v39 的輪廓外起播。

## 效能修正

- 網頁版固定 1280×720 的 Viewport 渲染目標，再縮放到瀏覽器畫面。1080p 輸出的像素量降至原來約 44%，4K 為約 11%。這是像素工作量比較，不能直接換算為 FPS；原生版維持 HD，邏輯座標、輸入與碰撞不變。
- 地形與前後景邊緣裝飾只提交鏡頭附近內容，採 384 世界像素的量化區域與額外安全邊界；鏡頭跨區才重建保留繪圖指令。地形裁切保持原世界座標材質 UV；碰撞、路線、房間生成與地圖資料不裁切。
- 普通／菁英怪依實際貼圖幀、面向與受傷色變更新繪圖，不再每秒 30 次重建未改變的同一姿勢。位置與鏡頭仍每幀更新。
- 安全屋站點插畫移至保留圖層，互動提示仍動態更新。景深材質、羽毛區域貼圖與邊緣素材清單快取；未集氣／無掉包時不建立相應粒子，也不要求無效重畫。首頁前景僅在位置變化時重畫。

## 驗證

`tests/test_combat_performance_v40.gd` 覆蓋實際單／雙 C 與下砸輸入、攻擊時鐘、粒子來源與方向、鏡像、原生／Web 渲染設定、鏡頭裁切安全區，以及怪物移動與轉向的繪圖快取。v38/v39 的碎羽測試同步新版中心起播規格；v08 與輸入經濟測試同步 v39 已取消獨立大刀／腳爪的規格，保留道具消耗與按鍵驗證。

`tests/benchmark_render_v40.gd` 在固定種子 171、第一張戰鬥房（2208×1056、17 塊實體地形）暖機後量測繪圖指令重建中位數：整房約 1629 µs，鏡頭區域約 1110 µs，減少約 32%。這是 headless CPU 重建耗時，不是瀏覽器 FPS 或 GPU 效能；數值隨機器負載變動。

驗證瀏覽器缺少 WebGL 2，不能在此環境完成瀏覽器畫面、操作手感與使用者裝置 FPS 的實機驗收。完整匯出回歸、容量與分片雜湊檢查另由 `scripts/build_web.py` 執行。
