# v0.17 地圖密度與RD文字修正

## 地圖

- 單格物理尺寸由64px改為96px（×1.5），地形貼圖週期、塔世界座標、地圖中心／房框與3格門的光效、碰撞開口／觸發範圍同步更新。
- 「房間基準大小−50%」以生成器的寬高格數各減半、向上取奇數處理：原寬33／37／41／45／49→17／19／21／23／25；原高17／19／21／23→9／11／11／13，去重後高度選項9／11／13。由於格子同時放大，普通房實際寬高約為原來75%，而不是人物縮放。
- 固定功能房最小17×11格（1632×1056px），保留整備二樓、商人與獎勵展示桌、浴池所需尺寸。最小縮放一律以最小普通房為準，避免進入功能房時主角忽大忽小。
- 刪除所有生成的薄實心支撐：48×16階梯、60×14門口踏板、16px厚浮空橫板。攀爬路徑使用至少144px寬的單向跳台，可以由下往上穿透及向下跳落；投射物也不再把它們當牆。
- 原生整塊牆與地板維持實心，隨機跳台仍僅在寬高大於5格的空洞生成。隨機跳台與必要通路分開記錄，避免用房間空間變小作為塞滿隨機平台的理由。

## RD美術室

- 根因：只在外層Control做font override，沒有為子控制項提供Theme。改為Theme.default_font與RichTextLabel各種字型共用，三個下拉PopupMenu也明確指定同一Theme。
- 字型重新從GDScript及解碼後的素材JSON字串建立；所有RD名稱、分類、說明的中文字形均由實際資源測試覆蓋。UTF-8來源未發現損壞，問題包括字型未繼承與素材說明缺字。
- 左側固定顯示搜尋框（含清除按鈕）、分類、動畫／靜態篩選、清除全部條件。支援不分大小寫的ID、多關鍵字交集，以及鴿子／主角、走路／行走、附武器／副武器同義詞。
- 篩選後自動選取匹配項目；零結果時清空舊預覽並停止播放，保留搜尋與清除入口。

## 驗證

`test_v17.gd`覆蓋新格距與尺寸、跨房世界座標、四個種子全房進入點、沒有薄實心平台、跳台不擋彈、子控制項與PopupMenu實際中文字型、全部目錄中文字形、1280×720控制項配置、多條件篩選、零結果及還原。

沿用真實34×42碰撞體、530跳速與1250重力的82房／172出口可達測試，保留既有戰鬥與物品測試。舊的固定座標戰鬥測項已明確設定其測試房界，避免把1050px測試地板放在新864px高房間外。

最終檢查：28／28本地回歸、12／12實際WebPCK測試通過，Web資源分片SHA256核對通過。內部瀏覽器確認v0.17載入頁，但回報缺少WebGL2及Secure Context，無法進入遊戲做實機視覺驗證；中文字型採實際子控制項與素材說明逐字形檢查。
