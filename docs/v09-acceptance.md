# v0.9 更新與驗收

日期：2026-10-22。接續v0.8，保留既有遊戲規則與存檔。

| 使用者回報／要求 | 本次變更 |
| --- | --- |
| 走路、攻擊、集氣忽大忽小 | 前版使用各動作外框的高度縮放，蹲身與翅膀張開會改比例。本版改用走路鴿子的固定虹膜面積作為解剖尺寸基準；所有已校準的攻擊／集氣圖共用這個比例，不再依姿態外框改大小。回血、衝刺與轉身圖也使用同一尺寸基準 |
| 走路加轉身動畫 | 新8幀側面→斜面→正面→另一側，約0.24秒；支援反向播放與途中改向；腳底各幀有錨點。攻擊、跳躍或衝刺會中止轉身，操作不延遲 |
| 中景加入平台式結構 | 每間房加入4組L式支柱與方塊中景模組，沿用該生態木頭／岩塊圖，使用中景視差與模糊，無碰撞 |
| 平台增加L、垂直、方形，減少橫條 | 普通房至少一組L實體、更多方塊與直立構件；可通過驗證的主路線平台可加端部支柱或底部方塊。可選橫向支線由3–6減為0–2。整備房與Boss房維持原空間需求 |
| 遠景偶爾有鳥飛過 | 專用4幀振翅圖，約9–17秒間隔，左右皆可飛過，遠景視差，不參與戰鬥 |
| 近景偶爾蜻蜓飛起 | 專用4幀振翅圖，約12–22秒間隔，從畫面下方起飛並擺動上升，近景視差，不參與戰鬥 |
| 死亡羽毛放大、漂浮、發光、掉小白羽毛 | 以v0.8可見尺寸60×40為基準，再放大為120×80；上下12px浮動、更大柔光；24顆原生CPU小白羽毛粒子持續向下飄落。取回掉包或離開該房即停止 |
| 門葉子要明顯吸入 | 30片可辨識葉形，由176px外圍旋轉收束進門心；粒子尺寸、亮度及密度增加，帶細脈與短拖尾。畫面外的門不繪製這批粒子 |
| 門依目的地發光 | Boss鮮紅、整備／商人／溫泉安全區鮮綠、獎勵金色；普通房淡白；尚未解鎖的門維持鎖定色 |

驗證入口：`python3 scripts/verify.py --godot <Godot路徑>`。17組回歸測試，包含600種子地形與419次真實向上跳躍換房；新增test_v09包含尺寸校準、轉身／中途反向、L地形通行、中景無碰撞、野生物移動、葉子收束、門色及死亡羽毛原生粒子。

實際Web匯出PCK再執行v08、controls_v07、v09三組測試。PNG原圖、匯入記錄與來源程式均保存在專案版本庫。新美術：

- `assets/atmosphere_v09/turn.png`：主角8幀轉身。
- `assets/atmosphere_v09/bird.png`：遠景飛鳥4幀。
- `assets/atmosphere_v09/dragonfly.png`：近景蜻蜓4幀。

三張皆使用內建imagegen，透明背景，保留原始PNG，直接以圖集區域讀取，沒有圖像混合插幀。轉身圖使用既有walk_00作角色參考。Prompt摘要：exact pigeon identity, eight actual 180-degree turning poses with planted stepping feet and constant anatomical head scale; separate four-frame wingbeat atlases for a slate forest bird and four-winged teal dragonfly; ink outlines with painterly shading, transparent, no text or scenery.

驗證限制仍為遠端瀏覽器缺WebGL2，因此尚無瀏覽器實機畫面、混音或手感驗收；程式狀態、素材載入及匯出測試通過不能代替這些人工檢查。
