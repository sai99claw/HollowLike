# v0.35 全面檢討第一批修正

本版由已發布v0.34開始，將已實際重現的Boss、交易、操作與UI缺陷分為四組修改、整合後發布。

- Boss改用累積失衡：不再每次微量命中都刷新硬直；打出失衡可中斷攻擊並獲得反擊空檔，之後有5.5秒保護期。
- 六Boss於65%及30%血量進入新階段，等當前招式完成才轉換；第二階段解鎖固定的生態招式。保留原血量與3隻菁英。
- Boss選招參考距離、高度與近期出招紀錄；掘王加入地面陷阱後散射及近距離爪擊分支。普通受擊姿態不再掩蓋Boss前搖。
- 商店先確認實際取得成功才扣款與售出；+8、滿16把與試用物品都依正式背包判定。
- 1／2／3恢復切換主武器；Shift+1～9使用補給，裸數字未綁動作時仍可使用相應補給。
- 按上與攻擊確認使用同一個最近站點；靠近假人時保留試打。
- 無雙齊射固定基礎0.60秒、前搖0，受攻速符文與RD參數調整；不因選取不同附武器改變，裝備頁顯示實際週期。
- 觸控搖桿斜上移動不再誤判為垂直向上而擋住衝刺；單下C不前衝、雙下CC直砸保持。
- 補齊肉鴿等中文字形，增加字型完整性檢查；安全屋只展開最近站點完整提示。
- 首頁移除重疊底註與戰鬥狀態欄，保留單一練習入口；RD工具移至設定的「練習與檢查」。
- 倉庫存檔以驗證過的暫存檔替換，保留上一份有效備份；損壞主檔可以備份恢復，失敗有提示。
- Web候選輸出完成驗證與容量檢查才替換上一次成功輸出，未移除runtime素材。
