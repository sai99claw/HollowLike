# v0.10 更新與驗收

| 項目 | 實作 |
| --- | --- |
| 羽毛刀 | 普通三階段相對v0.9加速1.5倍，所有方向／連段／集氣的判定高度×1.2，水平範圍不因此改變；集氣打擊期仍1.5秒 |
| 集氣 | 循環播放原有集氣美術，36顆原生吸入粒子，充滿時轉暖金色、顯示蓄力環；不依賴判定框開關 |
| 出招輸入 | 主攻擊按下時若攻擊忙碌或受傷即丟棄；放開後也不補打一刀，保留可出招時的按住集氣 |
| 門 | 門外透入的寬柔光束；42顆半透明白色微粒從房內緩慢向門流動，沿用Boss紅、安全綠、獎勵金；只穿過門口換房，E／上／攻擊不會把附近人物傳送 |
| 失焦景物 | 蜻蜓以大範圍模糊、半透明近黑輪廓呈現；鳥從中景尺寸逐步縮小並淡入遠景消失 |
| 草 | 平台長出保存於房間狀態的草叢；近戰／投射物可砍斷，每株只觸發一次與武器相同的長攻擊光效及草屑 |
| 垂直柱、實體面 | 移除透明樹皮外露出的實色矩形底板；碰撞與除錯框仍由原本開關控制 |
| 溫泉 | 全新透明手繪岩池4幀圖集，帶水波及蒸氣；共用腳底基準，保留原回血回能機制 |
| 角色清晰度 | 走路由80px執行圖改用現有256px原始圖，縮放與腳底定位維持原66×57可見尺寸，與戰鬥貼圖採同級來源解析度 |
| 雨 | 四種戶外生態中，固定種子四分之一的房間有遠／中景兩層半透明雨；原創8秒雨聲循環，遵守聲音開關及選單暫停 |
| 陷阱 | 投射物落地時從中心回推實際支撐平面，涵蓋平台與實體柱頂；側撞時放在下方地面，避免懸空；圖集可見底緣對齊地表，HP為1 |
| 怪物 | 五類固定招式、全新16格專屬生物彈體／陷阱／可愛蟲圖集；近身停止區、重新追擊距離與轉身遲滯抑制左右抖動。所有Boss可衝鋒；覺醒攻擊延用各物種素材 |

測試入口：`python3 scripts/verify.py --godot <Godot路徑>`。

新增v10整合測試涵蓋每方向／連段判定、輸入不排隊、集氣原生粒子、走路高清來源、割草命中、陷阱貼平面、直接穿門、雨層與靜音、遠鳥縮小淡出及門粒子軌跡。怪物測試另讓六Boss各在主程式真實戰鬥迴圈運行36秒，要求保留原遠程發射與至少兩次真正移位的衝鋒。更新舊測試的羽毛刀速度／走路圖源契約及怪物固定招式契約，敵人命中光效測試排除新草叢的額外命中。

網頁建置會對實際匯出的PCK再執行v08、controls_v07、v09、v10及monster_v10五組回歸，並驗證拆檔重新組合後的大小與SHA256。

本環境遠端瀏覽器缺少WebGL2，因此無法完成瀏覽器畫面、混音及操作手感的人工驗收；以上為程式、資源、實際戰鬥迴圈及匯出檢查。
