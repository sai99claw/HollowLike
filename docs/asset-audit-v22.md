# v0.22 貼圖使用與清晰度稽核

目前圖庫共695項素材、1607張來源圖。素材已實裝363項，標記`un-used` 332項；來源圖使用712張、保留未使用895張。

「已使用」表示目前遊戲的渲染路徑有接入；RD預覽本身、歷史備用圖及已替換版本不算。原圖保留，沒有刪除。

## 密度與替換

以來源像素／遊戲世界像素比較，不能用列印PPI判斷。舊跳躍、貼牆及首領身體多為約1:1，現在由v0.22獨立原畫取代。一般怪物攻擊／受傷由約70～150px角色改為約164～334px角色，並使用一物種一個固定比例。

- 保留原行走主圖256px（3.2px／遊戲像素）。
- 新三生態地形內部560～640px，覆蓋288世界像素，並先畫不透明底，四邊填滿碰撞框。鏡像方向每6格才改變。
- 每種生態1／2／3／4格平台各有獨立圖，固定等比標定。
- 新死亡12種、陷阱4種，以及主角空中／貼牆／瞌睡動作皆為獨立原畫。
- 清晰度仍需在實際WebGL畫面確認；純資料稽核不能保證不同原畫筆觸完全一致。

## 使用狀態

完整逐項、逐檔記錄在`assets/v22/asset-audit.json`。RD矩陣可按分類、動靜態、使用狀態與名稱／ID搜尋，且每項可複製ID。

原v0.15的18種小物件現在會混入地圖可砍物件，保留其破壞動畫；舊中景背景已停用，改為大型／中型世界物件的暗色半透明版本。
