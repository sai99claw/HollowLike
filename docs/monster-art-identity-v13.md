# v0.13 怪物美術身份稽核

2026-10-23，基於最新 v0.12 原始碼與當時未提交的 v0.13 修改，未回退其他工作。

問題不是一般怪原始圖片被錯誤命名，而是兩個映射及一個備援路徑會換掉整個身體：

1. `CombatVisual.enemy_clip` 原本對所有菁英的前搖／打擊／後搖，無條件選 `elite_biological` 或 `elite_weapon`。兩組圖實際都是枝葉樹精／螳螂，而菁英移動則用它原本的甲蟲、橡實精、蛾或獨角衝蟲，所以一出招就變成另一物種。現在菁英仍選自己物種的 attack，手持武器獨立疊畫。
2. 可愛葉帽糯糯蟲的平常繪製是自己的圖，但受擊粒子與死亡由 `FX.enemy_clip` 選圖，原本會走到 `enemy_walk_*`，變成苔甲蟲。現在所有狀態與受擊粒子都有專用 `enemy_pillbug_*` 紋理身份，精確裁取原 pillbug 區域。
3. 主場景舊 `Sprites.enemy` 依 model 的通用類別備援，其中 dash 的 model=5 會被視為 guardian。現在 MonsterDesign 專用身體繪製攔住這條備援：缺少 attack/hurt 等姿勢只回到同一物種的 move；整套自身素材都缺失時也不替換成其他物種。

另移除 Boss 的歷史程序化異種備援：trunk 的舊備援含 woodpecker（啄木鳥），與目前琥珀鍬形蟲不同。現在缺少 Boss 姿勢只保持本 Boss 的 move 圖，無有效 biome 時不猜成 branches 蛛后。
