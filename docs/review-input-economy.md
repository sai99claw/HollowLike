# 全面檢討修正：操作與交易

- 已指定的按鍵優先執行綁定動作；預設1／2／3可直接選擇主武器。Shift+1～9使用指定補給，未綁定的數字鍵保留補給捷徑。
- 商人正式購買先歸還試用品，再依真實行囊檢查上限。肉鴿+8與無雙16把不扣款、不標記售出；確認成功取得後才提交付款及售出狀態。試用中的臨時第16把不會誤判行囊已滿。上限也呈現在商品說明與購買按鈕。
- 安全屋按上與攻擊確認使用同一個最近站點。距離最近的是假人或能量花時，攻擊仍用於試打，不會打開旁邊的鍛造台。
- 無雙齊射採固定基礎0.60秒週期，前搖0；調教的後搖倍率與攻速符文仍生效。選取不同預覽武器不再改變整包齊射速度。面板透過`musou_cycle_seconds`顯示實際週期。
- 觸控搖桿的上方命令須以垂直方向為主（垂直幅度超過水平的1.2倍），斜向跑動不再誤持續按上而封住衝刺；向下判定保持原規則，保留單下C不前衝、雙下C直砸。原生與網頁觸控橋接一致。
