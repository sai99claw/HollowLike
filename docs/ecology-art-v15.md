# v0.15 三生態系美術

地圖由六關向上連通的塔構成。第1–2關屬於土色地底，第3–4關屬於綠色樹幹，第5–6關屬於藍色天空；美術分區對應既有地底、古樹與天空音樂。角色、敵人與武器保有既有比例。

每個生態系提供獨立遠景、中景、前景、地形圖集及可砍物件圖集，位於 `assets/ecology_v15/`。`scripts/biome_art_v15.gd` 延遲讀取圖檔，依 PNG 實際長寬建立圖集區域，避免假設生成圖片尺寸。圖檔缺漏時回傳 false，不混用其他生態系圖像。

## 地形圖集

每區地形檔為透明背景 **2欄×2列**：左上為可重複的實心內部材質，右上為上緣18%有機表面加下方實心材質，左下為垂直置中的薄單向平台，右下為帶不規則外緣的實心方塊。遊戲按64像素的材質週期平鋪，末端裁切而不拉伸；圖像不決定碰撞。

## 生成提示重點

- 共通：2D橫向平台遊戲、精緻手繪、不含字與角色、同生態系材質及光向一致；中景／前景／圖集使用真正透明背景。
- 地底：暖赭、焦茶、陶土、少量琥珀微光；根與頁岩帶出空間深度。
- 樹幹：主色祖母綠、翡翠及深苔綠，木質紋理仍可辨識；金色微光限於小面積點綴。
- 天空：主色鈷藍、天青及柔白，低對比空氣透視；浮石、羽草與陶釉沿用藍色系。
- 物件圖集：精確5×6等分網格、沒有格線與標籤、每列獨立材質、五格固定尺寸和共同腳底位置；破壞四格有明確的切開、爆散、下落、殘跡變化。

## 商人房獨立新景圖

`merchant_far.png`為透明的拱形木造店舖框景，三個大窗保留當地生態景色；`merchant_mid.png`為獨立布幔、吊燈與植物吊束。兩張均由內建ImageGen另行生成，不覆蓋既有三桌、試用與購買互動。提示：精緻手繪木造貓頭鷹商店、暖琥珀燈光、真正透明背景、不含角色與商品、中央75%及畫面下方留白，讓桌子與玩家保持清晰。
