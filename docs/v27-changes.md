# v0.27：選單分組、合成結果與戰鬥表現

## 介面

- 冒險選單改為雙欄，左側選「冒險與進度、操作與鏡頭、畫面與聲音、練習與檢查」，右側只顯示同組設定；滑桿仍支援方向鍵。
- 鍛造與重鑄的下方新增圖示結果卡，顯示剛取得的物品、效果及重複強化度，瀏覽下一件不覆蓋剛合成的結果。
- 死亡返程改為符文方格、大圖、效果說明與明確確認按鈕，保留空手返回選項。選格子先預覽，確認後才帶走一枚。
- 整備房E附武器、藍圖台、倉庫、商人與獎勵房的武器檢視加入大型貼圖與循環發射預覽。預覽對應九種行為：直射、連鎖閃電、爆炸拋物線、反彈、追蹤、落地陷阱、飛斬、地面燃燒與雷射。
- 獎勵房互動先開啟預覽，再確認領取，避免直接選走。

## 投射物與動畫

- 修正 `WeaponArtV24.draw` 未組合鏡頭平移／縮放的根因：投射物與雷射貼圖會與實際彈體位置一致，繪製後還原座標變換；移除原本顯眼的暗色圓形提示。
- 燃燒瓶空中使用瓶身貼圖；落地後使用全新四幀火焰素材，沿地面延展，四秒持續燃燒與上升火星粒子。火焰依實際承載地面放置，標準／精簡模式皆保留粒子並遵守全域上限。
- 二段跳啟動一次0.32秒四幀搧翅，固定比例與各幀腳底定位，避免展翅造成角色縮小。完整提示及素材資料見 `v27-fire-art.md`、`v27-flap-art.md`。
- 商人桌、獎勵桌、站點、寶箱、跳台、假人與可破壞物的美術向地圖方塊內嵌10世界像素，保留遊戲碰撞與互動位置。

## 數值

- 菁英現有血量乘3，包含地圖增長及Boss護衛；練習召喚亦一致。Boss本體與一般怪物不變。
- 單C與雙C水平衝刺在相同持續時間內移動距離乘1.5；向下雙C仍是落地終止的下砸。
- 被攻擊後的無敵時間乘1.5，Roguelike基礎0.55→0.825秒、無雙1.2→1.8秒，符文提供的保護加成一併縮放。

## 資源與驗證

- 新火焰及搧翅原圖保留於 `assets/v27`，執行時無損匯入至最多1024px。
- 兩張僅供原始交付／美術審核的v24完整武器圖集留在來源，Web不再重複封入；實際逐件武器與投射物仍全部匯出。輸出持續檢查256MiB上限與分塊SHA-256。
- 新增 `test_v27.gd`，驗證鏡頭座標、所有投射物資源、地面火焰與持續傷害、粒子上限、實際雙跳啟動與結束、菁英血量、衝刺位移、受傷無敵時間、死亡選擇、合成結果、附武器預覽及分組設定。

最終驗證：Web發布包26/26組回歸通過，PCK224874952bytes，WASM39514754bytes，分塊雜湊與輸出總容量264706807bytes均通過。另在原生CanvasItem繪圖流程逐一執行九種武器的發射及落地階段，未發現腳本／繪圖API錯誤。遠端預覽仍回報缺少WebGL2與Secure Context，因此未能目視驗證WebGL渲染、粒子外觀及實際滑鼠畫面操作；未變更瀏覽器安全設定。

發布封裝額外驗證：恢復工作目錄中出現一個不屬於遊戲的中斷分塊暫存檔，初次封裝因此被容量檢查退回。新增 `validate_web_output.py` 作為來源封裝流程的最後檢查，清除這類暫存檔、重新核對兩份分塊manifest的大小與SHA-256，再檢查總容量；遊戲資源未刪減。
