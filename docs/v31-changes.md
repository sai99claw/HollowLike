# v0.31 投射物重製

七種實體附武器投射物各有8張繪製幀（4×2透明圖集），包含兩張受控的動態smear。炸彈順時針、陷阱莢逆時針、燃燒瓶較慢順時針；迴旋環逆時針、月刃快速順時針；針彈與追蹤飛彈保持朝向飛行方向，用軸向翻滾/側傾表現。

動畫使用實際模擬elapsed，停頓時凍結。投擲物不再每幀以拋物線切線重新轉向；旋轉由貼圖幀供應。保留主角身高1/5的基準尺寸與每枚尺寸符文5%加成。

移除新系列的四份深色疊影、大光暈與粗彩色帶狀拖尾，改為短壽命、少量、低飽和灰塵陰影粒子。粒子留在經過的世界位置，不會跟著物件整串平移。商人、獎勵及裝備頁預覽也使用同一動畫。

閃電與雷射是瞬時光束效果，沒有實體投擲物，維持其既有行為。地面燃燒與已落地的陷阱仍使用各自場景素材。

附文心得與採用範圍：v31-art-principles.md。各圖集提示詞及生成紀錄另列於v31美術文件。
