# v0.19 地圖變化與參數調教

地圖重複的原因：縮小房間後，固定滿高廣場、另外兩個廣場、上下各兩格空白邊帶覆蓋了大部分 Prim 迷宮。此版取消每房必出的滿高廣場，上下邊帶縮為一格，保留左右安全攀登通道。

六種房型依種子打亂抽取，抽完再洗牌，避免連續同型：窄徑柱林、階梯迴廊、分隔雙廳、開闊洞廳、垂直豎井、環形迴廊。一般廣場改成 3～5 格；洞廳與豎井才使用全高。必要導航單向平台仍維持可穿越，門寬仍為三格。

| 項目 | 新預設 |
|---|---|
| 塔的縱向生長權重 | 68% |
| 基準直線偏好 | 55%，再依房型調整 |
| 基準死巷打通率 | 45%，再依房型調整 |
| 普通怪生成機率 | 原先 ×1.2，數量上限同步調高 |
| 集氣 | 2 秒降為 1.4 秒；完整施放仍為 1 秒 |
| 移動、跳躍、單 C | 保留集氣；有效受傷與施放攻擊會中斷集氣 |
| 待機 | 八個獨立姿態，8 fps；閒置五秒開始以 8 fps 趴地休息 |
| 背景飛鳥 | 停用，前景蜻蜓保留 |

Boss 在本關只有一個左／右入口。通關出口仍向上連接下一關整備房。Boss 具有依身體框計算的獨立場內邊界，門洞、衝鋒及擊退都不會讓牠離場。

副武器切換不限制兩把：資料載入時統一新舊武器格式，Q 輪替整個背包；切換會取消上一把副武器的前後搖。施放仍需一格能量。驗證涵蓋全部 11 種武器的實際輸入與施放。

首頁新增「RD 參數調教」，分為地圖生成、怪物與戰鬥、移動與集氣，共 18 個參數。提供數字輸入、滑桿、全塔／房間預覽、下一間房、恢復預設、儲存與取消。設定保存到遊戲存檔，於下一次冒險或練習套用；已生成房間保留原樣。固定種子為 0 時使用隨機種子，房數為 0 時每關隨機 6～8 間。

新美術使用內建 imagegen，保存在 `assets/v19/pigeon-idle.png` 與 `assets/v19/pigeon-rest.png`。完整提示詞在 `assets/v19/idle-prompts.json`，逐幀區域與固定縮放校準在 `assets/v19/idle-manifest.json`。RD 美術室可搜尋「待機呼吸」或「趴地休息」。

自動驗證包括 50 個種子的數百個戰鬥房配置（比較中央實體地形與密度跨度）、全塔連通、實際跳躍可達性、Boss 六物種四邊越界、集氣規則、待機時序、全部副武器、RD 設定儲存與下次套用。實機 GPU 畫面與 FPS 仍需在支援 WebGL 2 的瀏覽器確認。
