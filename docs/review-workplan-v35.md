# 全面檢討第一批修正派工

日期：2026-10-29（台灣）

來源：v0.34、55張原生引擎截圖、366個房間結構檢查與六Boss隔離行為測試。此批從已發布的 v0.34 原始碼開始；先前未保存的浮空彈跳物、獨立中景視差及大型月牙等修改不包含在這次修復內，不能視為已恢復。

## 分工與整合

| 工作組 | 本批範圍 | 驗收重點 |
|---|---|---|
| Boss戰鬥 | B01、B02、B03部分：Boss姿態/硬直、血量階段、上下文選招與前搖可讀性 | 每0.1秒微量命中不再永久封招；階段可重現；死亡不出招；小怪受擊規則保留 |
| 操作與交易 | U01、U02、U05、E01、E02 | 數字主武器鍵可用；站點最近目標一致；滿強化不扣錢；無雙節奏不隨選取游標改變；保留單下C/雙下C規格 |
| 介面與字型 | U03、U04、U06、A01部分 | 肉鴿文字字形齊全；安全屋只展開一個站點詳細提示；首頁說明與開發工具不遮住遊戲 |

| 整合 | 各組原始碼審查、回歸、原生畫面檢查、Web打包與發布 | 逐項記錄實測結果；原始碼提交可恢復；保留公開存取與意見回饋後端 |

各組使用獨立Git worktree；整合後再做一次跨功能回歸。未經真人試玩支持的平衡猜測不直接當成缺陷修正。

## 測試解讀

微量連續命中是隔離診斷，用來證明AI能否正常開始攻擊，不代表正常玩家勝率或樂趣。血量階段數值與姿態參數是第一版待調整設計；需以真人Boss試玩記錄驗證挑戰、可讀性與公平性。
