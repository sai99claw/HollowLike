## 1 遊戲結構

遊戲為 2D 平台動作冒險。主角是一隻鴿子，從樹上出發，在沿樹上下延伸的塔式房間群中冒險。玩家透過跳躍、貼牆、衝刺、主武器攻擊及副武器應對敵人，收集符文、武器、強化、消耗品與金幣，擊敗 Boss 後繼續推進。

基本流程：鳥巢與樹的入口場景選擇模式 → 第一張圖的初始整備房 → 探索與戰鬥 → 取得掉落與選擇獎勵 → 擊敗 Boss → 相鄰的下一張圖初始房。一次冒險共六張圖，完成第六張圖後結束本次冒險；通關獎勵與結算細節待定。

遊戲提供兩種模式，由入口場景的門選擇；設定保留模式選項：

| 規則 | 無雙 | Roguelike |
| --- | --- | --- |
| 核心體驗 | 大量清怪、持續成長、容易打出強烈打擊感、較低死亡壓力 | 操作、閃避、拼刀與技術流派 |
| 主武器成長 | 局內強化可累加 | 攻擊傷害固定；固定傷害涵蓋範圍見第 6 節 |
| 主要戰鬥掉落 | 主武器強化與副武器強化 | 符文與副武器 |
| 副武器持有 | 強化效果可累加；是否保留多把切換待定 | 可持有多把，在背包切換 |
| 消耗品掉落率 | 10% | 10% |
| 消耗品取得後 | 立即施放 | 收入背包，手動使用 |
| 生存參數 | 較長無敵時間、較大擊退距離、較高補血包掉落率 | 使用較嚴格的基準 |
| 敵人增加幅度 | 比 Roguelike 大 | 隨關卡增加數量、強度與種類 |
| 金幣與造型 | 掉落金幣，可購買 skin | 相同 |

入口場景選擇的模式用於接下來的冒險。設定選項與兩扇門的同步顯示方式，以及進行中的冒險能否切換模式與如何處理進度，待定。

### 1.1 入口場景與模式門

- 場景背景為鳥巢與樹，玩家以鴿子角色左右走動選擇入口。
- 場景有兩扇模式門：「轉頭的起飛鴿子」對應無雙；「帥氣的戰士鴿子」對應 Roguelike。
- 進入選定的門後，抵達該次冒險第一張圖的初始整備房。
- 接近門後的確認輸入，以及轉頭、起飛與戰士鴿子的具體動畫表現待定。

## 2 操作輸入

### 2.1 基本動作

玩家具有方向、跳躍、衝刺、主攻擊、副武器與回血等基本操作。進階動作透過既有按鍵的方向組合、長按、放開與快速雙擊觸發，不增加專用技能鍵。背包、地圖及設定屬功能介面。

| 操作 | 輸入 | 規則狀態 |
| --- | --- | --- |
| 左右移動 | 左右方向鍵；WASD 不預設綁方向 | 預設方向鍵，設定可自訂 |
| 跳躍 | 跳躍鍵，原型為空白鍵 | 地面起跳 |
| 二段跳 | 空中再次按跳躍鍵 | 技能樹解鎖 |
| 貼牆停駐 | 解鎖攀牆後，接觸可貼附牆面 | 不向下滑落；視同落地，恢復落地可恢復的移動資格 |
| 牆跳 | 貼牆時按跳躍鍵 | 技能樹解鎖；跳躍方向與脫牆規則待定 |
| 一般衝刺 | 單按 C | 第一下按下立即衝刺，不等待雙擊判定 |
| 雙衝 | 第一下 C 後 0.5 秒內再按 C | 第二下觸發穿刺，短暫無敵；整組總距離超過單按 C |
| 橫向雙衝 | 橫向狀態下快速按兩下 C | 左右方向如何取決於輸入或面向，待定 |
| 向上雙衝 | 上方向搭配快速按兩下 C | 垂直向上強化衝刺 |
| 向下砸地 | 下方向搭配雙衝輸入 | 持續下砸至地面，落地造成範圍傷害與粒子特效 |
| 普通主攻擊 | 主攻擊鍵，原型為 X | 可搭配方向出招 |
| 集氣斬 | 長按主攻擊後放開，搭配方向 | 橫向與縱向分別由技能樹解鎖 |
| 衝刺集氣斬 | 已蓄力時銜接衝刺並釋放 | 技能樹解鎖；確切觸發時機待定 |
| 副武器施放 | 副武器鍵，原型為 U | 無蓄力分支 |
| 回血 | 長按回血鍵 | 預設 A，長按引導回血，可自訂 |
| 地圖 | 原型為 Tab | 顯示房間分布 |

「雙衝」是快速雙擊的招式名稱，不能直接解釋為兩次空中衝刺額度。一般衝刺與雙衝各自的空中使用限制另行定義。

鏡頭預設 1.3 倍，Esc 設定可調整 0.8–2.0 倍；HUD 不跟隨放大。設定可重新綁定各動作，衝突時交換按鍵，Esc 固定保留作離開方式。縮放與鍵位寫入本機存檔並於下次開啟恢復。

### 2.2 輸入邊界

- 同一個 C 輸入流程中，第一次按下、放開與第二次按下需被辨識為同一組雙擊。
- 第一下 C 立即執行一般衝刺；從第一次按下起算，第二次按下需在 0.5 秒內，才算同一組雙衝輸入。
- 以兩次獨立按下事件判定；持續按住 C 的鍵盤自動重複不算第二次按下。
- 第二下觸發穿刺衝刺；同一組輸入的總移動距離必須大於單次一般衝刺。
- 已符合雙衝條件時，不能單因第一下耗掉空中一般衝刺資格，就拒絕第二下的穿刺銜接。技能解鎖、能量及其他限制仍依各自規則處理。
- 第二次按下時取用的方向、第三次按下能否開啟新一組輸入，以及雙衝後的再次施放條件，待定。
- 集氣期間的方向可以在何時改變，以及放開主攻擊時是否鎖定方向，待定。
- 方向鍵同時作為進門輸入時，進門與戰鬥動作的優先順序待定。
- 手機端需使用對應的長按與雙擊操作，不另設專用雙衝或集氣技能鍵。

## 3 移動與平台互動

### 3.1 跳躍與二段跳

角色具有地面跳躍。原始 HTML 雛形支援依按住時間調整跳躍高度，可作為移動基準；目前可玩原型採固定起跳初速，尚未移植按住時間控制跳高。正式跳躍曲線待調。

二段跳由技能樹解鎖，在空中再按跳躍施放。落地會恢復跳躍資格；解鎖攀牆後，貼牆視同落地，同樣恢復二段跳等落地可恢復的移動資格。下劈反彈或命中敵人是否另外恢復二段跳，待定。

### 3.2 貼牆與牆跳

確定規則：

- 角色貼牆後停駐，不自動下滑。
- 貼牆時可以按跳躍鍵跳開。
- 解鎖攀牆後，成功貼牆視同落地：二段跳、空中衝刺等原本由落地恢復的移動資格，使用相同的恢復規則。
- 「視同落地」指移動資格與狀態恢復，不自動視為下砸撞地或觸發其他地面範圍攻擊。
- 本版不將攀牆定義為持續向上爬行；是否增加上爬能力需另行決定。

尚未設定貼牆體力、最長停駐時間或自動滑落倒數，不預設存在這些限制。

待定：需要持續按向牆方向才能保持貼牆，或接觸後自動保持；鬆開方向、按反方向、攻擊、受擊、衝刺及開背包是否解除貼牆。牆跳使用貼牆時已恢復的移動資格；一般冷卻是否也因落地／貼牆重置，依正式落地規則決定。

### 3.3 衝刺與雙衝

第一下 C 立即執行一般衝刺；第一次按下後 0.5 秒內第二次按下 C，觸發穿刺衝刺。雙衝提供短暫無敵，並在穿過敵人時造成穿刺傷害，整組總距離超過單按 C。

| 項目 | 一般衝刺 | 雙衝 |
| --- | --- | --- |
| 輸入 | 第一下 C 立即執行 | 第一下 C 後 0.5 秒內再按 C |
| 移動距離 | 一般衝刺距離 | 第一段與穿刺銜接後的總距離大於一般衝刺 |
| 方向 | 原型支援橫向與上方向 | 橫向與垂直方向，由對應技能開放 |
| 穿刺傷害 | 不預設具有傷害 | 確定具有 |
| 無敵 | 原型具有短暫無敵；正式規格待調 | 確定具有短暫無敵 |
| 能量成本 | 原型不消耗 | 原型強化衝刺消耗 1；本版正式成本待定 |
| 空中限制 | 原型每次滯空可用一次 | 正式次數及與一般衝刺的關係待定 |

雙衝的速度、距離、持續時間、無敵區間、冷卻與同一目標可受傷次數，須各自設定。原型每次穿刺衝刺對同一敵人只造成一次傷害，可作基準。

第二下是第一段衝刺的穿刺銜接，不必等待一般衝刺冷卻結束。第一段尚未結束時是接續剩餘位移或立即切換穿刺，以及第一段結束後至 0.5 秒窗口截止前的銜接位移，需依同一套規則設定；總距離均須滿足超過單按 C 的要求。

### 3.4 下劈與下砸

下劈是向下的主武器揮擊；下砸是垂直強化衝刺的向下動作，兩者分開處理。

- 下劈：原型在命中敵人時使角色向上反彈，可銜接其他空中操作。
- 下砸：角色持續下降至有效地面，觸地時觸發一次範圍攻擊與粒子特效。
- 下砸途中能否取消、是否對途經敵人造成穿刺傷害、是否穿過單向平台，以及何種地面會終止下砸，待定。
- 下砸落地爆發的範圍及收招時間獨立設定；傷害與當前主武器普攻一致。

### 3.5 原型中的其他平台互動

原始 HTML 雛形具有下方向加跳躍穿下單向平台，以及接觸後自動彈起的彈跳板。目前可玩原型已有向下穿越單向平台，尚未移植彈跳板。這些可保留作為場地互動；其是否恢復衝刺、二段跳與蓄力狀態，需與正式移動規則一致。

必要通路必須可用當時已解鎖的能力通過。未取得的進階技能可以影響支線路徑，但不能使目前主線無法通行。

## 4 技能樹

技能樹隨遊玩次數、關卡進度或其他遊玩成果解鎖核心操作，門檻不拉高。正式解鎖條件、順序與跨模式共用方式待定。

| 技能節點 | 開放內容 | 依賴狀態 |
| --- | --- | --- |
| 二段跳 | 空中追加一次跳躍 | 與其他移動節點的先後待定 |
| 貼牆與牆跳 | 貼牆不滑落、貼牆可跳、貼牆視同落地 | 兩者合併或分別解鎖待定 |
| 橫向雙衝 | 橫向快速雙擊強化衝刺 | 技能樹節點 |
| 垂直雙衝 | 向上強化衝刺、向下砸地 | 下砸是否獨立節點待定 |
| 橫向集氣斬 | 左／右方向的集氣攻擊 | 與縱向集氣斬分開解鎖 |
| 縱向集氣斬 | 上／下方向的集氣攻擊 | 與橫向集氣斬分開解鎖 |
| 衝刺集氣斬 | 衝刺與集氣攻擊銜接 | 與方向集氣斬的前置關係待定 |

技能樹提供操作能力；符文不再負責解鎖二段跳、雙衝等核心動作。每個技能是否對三種主武器同時生效，待定。

未解鎖某方向集氣斬時，該方向長按攻擊的結果尚未定義，不能自動當成另一個已解鎖方向的招式。

| 向下砸地 | 按住下方向，依上列雙 C 觸發 | 耗 1 能量；下砸速度 1080；落至第一個有效平台或地面時，基準半徑 165、傷害與目前主武器普攻一致，僅爆發一次 | 目前不對下降途中的身體碰撞直接造成穿刺傷害；碰牆不算砸地 |
| 普通主攻擊 | X 按下後放開；未達集氣條件 | 不耗能；依三種主武器倍率；每個被命中的目標基準回 1 能量 | 攻擊方向在放開時決定；前一攻擊忙碌時，暫存一筆請求，待收招完出手 |
| 方向集氣斬 | 長按 X 至該武器門檻，放開時對應橫／縱技能已開 | 不耗能；目前傷害為該武器普通傷害 ×3，每個目標基準回 2 能量 | 疾羽／重刃／長槍暫用蓄力門檻 0.46／0.62／0.54 秒；未解鎖該方向則目前退回普通攻擊 |
| 衝刺集氣斬 | 已達蓄力門檻，在衝刺仍持續時放開 X，且 `dashcharge` 與該方向集氣技能已開 | 無額外能量費；目前集氣傷害再 ×1.25、距離再 ×1.15、擊退再 ×1.25 | 一般衝刺與穿刺衝刺均可觸發；可取消原攻擊時鐘、開始自己的三階段；無額外獨立無敵保證 |
| 副武器 | U 按下；已持有、能量至少 1，且攻擊時鐘閒置 | 耗 1 能量；刀劍為近戰，其餘於打擊期發射彈體 | 無蓄力分支；忙碌時按下目前不排隊，也不能取消主攻擊 |
| 引導回血 | 持續按 H；能量至少 3、生命未滿、攻擊時鐘閒置 | 每引導 0.7 秒耗 3 能量、回 1 生命；繼續按住可再次引導 | 鬆開、條件失效或受擊即重置本次引導；移動目前不自動中斷 |

目前主武器命中會恢復空中一般衝刺資格；使用共用近戰命中流程的穿刺與刀劍副武器也會恢復。向下近戰命中暫設向上反彈初速 440、跳躍使用狀態回到已用一次、至少 0.14 秒保護；這也會作用於朝下的刀劍副武器，適用來源尚未正式定案。一般彈體命中不走這套反彈／回衝刺流程。

### 4.3 動作接續與取消窗口（目前可玩原型）

目前是一套共用攻擊時鐘與暫存請求，尚未實作獨立的「連段等級」「完美取消」或每招可配置的取消窗口表。工程應按下表理解現況，不能只因兩個技能已存在就假定能無條件互相取消。

| 目前動作 → 新輸入／事件 | 現行處理 | 尚待決定的正式規則 |
| --- | --- | --- |
| 主攻擊任一階段 → 放開下一次主攻擊 | 等前一招結束後出手；只保留最近一筆請求，不形成多段佇列 | 連段段數、輸入緩衝長度、是否可取消後搖 |
| 攻擊前搖／後搖 → 第一 C | 可位移，但原攻擊時鐘繼續；不視為取消 | 哪些攻擊可被普通衝刺取消 |
| 攻擊打擊期 → 第一 C | 目前不執行一般衝刺 | 打擊期能否閃避取消 |
| 任一攻擊階段 → 合格第二 C | 耗能，取消原攻擊並開始穿刺的前搖 | 哪些技能應限制此取消，以及與雙擊窗口的優先序 |
| 蓄力就緒＋衝刺中 → 放開 X | 符合技能條件即開始衝刺集氣斬；若原攻擊忙碌則先取消原攻擊 | 各武器獨立的取消窗口、方向切換與無敵 |
| 任一攻擊階段 → U | 忽略本次副武器施放，不扣能、不排隊 | 主副武器取消或連攜規則 |
| 任一攻擊階段 → Space | 依地面／空中／貼牆資格跳躍；原攻擊繼續 | 是否按招式限制跳躍取消 |
| 玩家攻擊與敵人主武器打擊期相交 | 敵人攻擊取消並暈眩；玩家攻擊繼續，獲得保護與能量 | 精準時機、Boss 抗性及拼刀後專屬派生 |
| 玩家受傷 | 取消玩家攻擊、回血引導與衝刺／下砸狀態 | 霸體、不可取消攻擊與受擊保留輸入 |
| 開背包／設定等選單 | 暫停戰鬥，清除按住輸入、蓄力與待出手請求；已開始的攻擊時鐘暫停，關閉後繼續 | 選單是否一律暫停、是否保留蓄力 |
| 過房／重新進房 | 清除當前攻擊、彈體、衝刺與下砸 | 跨房保留項目與門口無敵規則 |

## 5 主武器

### 5.1 三種主武器

確定共有三種主武器，分別特化快攻、重斬與長距離，各自具有不同打擊感與集氣攻擊。具體名稱、外觀與集氣招式尚未指定，先以主武器 01、02、03 區分。

以下倍率以共同的普通攻擊基準為參照；未特別強化的欄位先按基準 ×1 記錄。集氣攻擊是否繼承同樣倍率，仍需各武器招式另行設定。

| 主武器 | 特化 | 攻速倍率 | 普通傷害倍率 | 攻擊距離倍率 |
| --- | --- | --- | --- | --- |
| 主武器 01 | 快攻連斬 | ×2 | ×1 | ×1 |
| 主武器 02 | 重斬 | ×1 | ×2 | ×1.5 |
| 主武器 03 | 長距離 | ×1 | ×1 | ×2.5 |

重刃另增加 0.05 秒前搖與 0.10 秒後搖，一般重刃為 0.16／0.12／0.37 秒。攻速 ×2 代表相同時間內可完成的攻擊次數為基準的兩倍，不是將攻擊間隔乘二。距離倍率指攻擊觸及距離，是否連同揮擊寬度或高度等比放大，待定。重斬的具體擊退效果另行設定。

| 攻擊項目 | 主武器 01 | 主武器 02 | 主武器 03 |
| --- | --- | --- | --- |
| 普通揮擊與方向攻擊 | 待定 | 待定 | 待定 |
| 出手、有效及收招節奏 | 待定 | 待定 | 待定 |
| 攻速 傷害 距離特化 | 攻速 ×2 | 傷害 ×2、距離 ×1.5 | 距離 ×2.5 |
| 命中反應與擊退 | 待定 | 待定 | 待定 |
| 橫向集氣斬 | 待定 | 待定 | 待定 |
| 上方向集氣斬 | 待定 | 待定 | 待定 |
| 下方向集氣斬 | 待定 | 待定 | 待定 |
| 衝刺集氣斬 | 待定 | 待定 | 待定 |

三種主武器的差異需反映在攻擊形狀、節奏、命中反應或集氣行為，不能僅由顏色區分。不同效果的具體設計尚未定案。

主武器的初始選擇方式、攜帶數量、局內取得及切換地點待定。副武器收集與切換規則不自動套用到主武器。

### 5.2 普通攻擊

主武器可搭配方向進行揮擊。原型包含前方、上方與下方普通斬擊，且採按住主攻擊後，在放開時判斷普通或集氣攻擊。

普通攻擊的按下／放開觸發方式是否延續原型，待定。若改成按下立即普通攻擊，需另定長按蓄力時是否會先多施放一次普通攻擊。

### 5.3 集氣斬

- 長按主攻擊蓄力，符合蓄力條件後放開施放。
- 橫向集氣斬與縱向集氣斬是兩個技能樹技能。
- 左右方向施放橫向效果；上下方向施放縱向效果，具體形狀依主武器而異。
- 上方向與下方向可具有不同結果，但同屬縱向集氣斬的技能解鎖範圍。
- 舊原型「所有方向皆施放同一個全周蓄力爆發」不直接作為三種主武器的共同正式規則。
- 每種武器的蓄力時間、範圍、傷害、位移及可取消行動獨立設定。

未輸入方向時的集氣斬方向，待定。

### 5.4 衝刺集氣斬

角色在集氣狀態銜接衝刺，於符合條件時釋放專屬攻擊。此技能由技能樹開放，使用既有衝刺與主攻擊鍵。

待定：一般衝刺與雙衝是否都可銜接；蓄力是否跨衝刺保留；釋放時使用何種方向；技能的無敵、能量消耗及收招；未解鎖方向集氣斬時可否施放該方向的衝刺集氣斬。

## 6 戰鬥資源與攻防

### 6.0 所有攻擊的三階段時序

玩家與所有怪物的每一種攻擊，均須具備前搖、打擊期、後搖三個時段。三個時段可以各自獨立控制，並具有各自的動畫，不可只更換傷害數值或共用一張靜止畫面。

| 階段 | 行為 | 動畫與判定 |
| --- | --- | --- |
| 前搖 | 起手、蓄勢或瞄準，提供出招預警 | 播放該攻擊的前搖動畫；未進入打擊期前不產生此招攻擊判定 |
| 打擊期 | 武器揮擊、穿刺、落地爆發或發射彈體 | 播放打擊動畫；在指定時間啟用近戰判定、移動攻擊判定或發射事件 |
| 後搖 | 攻擊結束後收招與恢復 | 播放收招動畫；該次近戰打擊判定結束，何種行動可取消後搖需依招式設定 |

- 每個角色、武器、攻擊方向與招式可分別設定三個階段的持續時間及動畫。
- 普通攻擊、方向集氣斬、衝刺集氣斬、雙衝穿刺、下砸攻擊、副武器、敵人普通攻擊與 Boss 招式均適用此結構。
- 投射攻擊於打擊期發射後，已生成的彈體依自身生命週期繼續飛行；發射者進入後搖不會自動刪除彈體。
- 集氣等待與攻擊三階段需分開表達；集氣完成不代表持續存在打擊判定。具體集氣與前搖的銜接依招式設定。
- 受擊、拼刀、死亡、閃避等是否中斷或取消某階段，需由招式規則明訂。
- 攻速加成如何作用於三個時段需明確配置，避免只加速動畫卻未同步判定。

### 6.1 生命與能量

| 項目 | 原型基準 | 正式規則狀態 |
| --- | --- | --- |
| 生命 | 上限 5 | 待調 |
| 能量 | 上限 6，初始 3 | 待調 |
| 普通主攻擊命中 | 基準傷害 1，回復 1 能量 | 傷害套用第 5 節武器倍率；回能是否共用待定 |
| 集氣攻擊命中 | 原始 HTML 雛形傷害 4；目前可玩原型為該武器普通傷害 ×3，回復 2 能量／目標 | 三種武器及不同方向需分別設定 |
| 拼刀成功 | 回復 2 能量、短暫無敵、敵人暈眩 | 效果基準待調 |
| 普通副武器 | 消耗 1 能量 | 待調；沒有蓄力費用或雙份射出規則 |
| 引導回血 | 消耗 3 能量，回復 1 生命 | 延續與中斷條件待定 |
| 雙衝穿刺 | 消耗 1 能量，單次傷害與目前主武器普攻一致 | 三種武器及無雙傷害強化同時套用 |

無雙的無敵時間及擊退距離較 Roguelike 增加；增加幅度與適用來源待定。

### 6.2 Roguelike 的固定傷害

確定不採用無雙式持續累加攻擊強化。第一章起始地圖的普通小怪，以普通攻擊基準傷害約三刀擊殺作為設定起點；三種主武器套用各自確定的攻速、傷害與距離特化。

不同武器的固定值可以不同：主武器 02 的普通傷害是共同基準的兩倍，對同一敵人按實際血量與傷害結算，不再強制三種武器都以相同刀數擊殺。例如沿用基準傷害 1、小怪生命 3，主武器 01／03 需三次命中，主武器 02 需兩次命中；此為倍率推導示例，不是新增生命數值定案。

待定：集氣斬、衝刺集氣斬、副武器及符文條件加成的固定傷害範圍，以及合成能否改變傷害。不同招式不預設具有相同傷害。

### 6.3 拼刀

玩家與敵人的主武器有效揮擊互相碰撞時，可發生拼刀／彈刀。拼刀、命中身體與攻擊落空為不同戰鬥結果，需有不同回饋。

原型以敵人正在揮擊、且雙方武器判定重疊作為觸發條件，成功後提供短暫無敵、能量與敵人暈眩，可作起始規則。精準時機窗口、方向、集氣攻擊適用性、Boss 抗性與同一揮擊重複拼刀限制待定。

### 6.4 主武器擋副武器彈體

玩家與敵人都適用主副武器系統；主武器揮擊可以擋下副武器的彈射物。

- 需要以主武器的有效揮擊與彈體發生互動。
- 成功擋彈需有明確的接觸效果及彈體結果。
- 擋彈後消除或反射、能否回能、方向要求與判定窗口待定。
- 爆炸、光束、地面衝擊波及其他非一般彈體的攻擊，能否被擋需各自設定。
- 同時命中武器與身體時，擋彈／拼刀與受傷的結算優先順序待定。

### 6.5 命中與位移連動

原型包含斬擊命中恢復空中衝刺、下劈命中後向上反彈等連動。正式版需設定適用來源：普通主攻擊、集氣斬、副武器、雙衝及下砸是否各自恢復衝刺或二段跳。

命中能量回復以每次攻擊、每個敵人或每次傷害事件結算，需明確定義；多段攻擊與多彈體不得因未限制命中次數而產生非預期的重複回能或受傷。

## 7 副武器與合成

### 7.1 武器類型

副武器可包含遠程、熱兵器、投擲、刀劍及多彈體等風格。每把武器可有近戰效果、彈射效果，或兩者組合。

每把副武器需明確定義：出手節奏、能量成本、近戰範圍、傷害、彈體數量與方向、速度、彈道、貫穿、回彈、爆炸或其他特殊效果，以及與主武器擋彈的互動。

副武器沒有蓄力操作。按住副武器鍵的連發、單次施放或重複施放方式待定。

### 7.2 取得與切換

- 1-1 初始房隨機提供一把副武器。
- Roguelike：拾取多把副武器後保留於背包，可在背包切換使用。
- 無雙：副武器強化效果可累加；是否同時允許多把武器持有與切換，待定。
- 首次取得的副武器是否直接裝備，以及其與原型預設副武器的關係，待定。

### 7.3 初始房合成

取得副武器後，可以在初始房消耗貨幣合成。

合成需定義投入武器、費用、合成後效果，以及材料與目前裝備的處理方式。合成之前顯示結果，不能因流程不清楚而誤消耗裝備。

以下規則尚未設定：

- 使用金幣或獨立貨幣。
- 材料數量、材料是否消耗，以及是否存在固定配方。
- 只使用目前背包武器，或曾取得就能永久解鎖合成素材／配方。
- 合成是增加數值、組合效果或兩者皆有。
- Roguelike 能否透過合成提高傷害。
- 無雙拾取時的即時累加與初始房付費合成，各自負責什麼效果。

## 8 符文盤與收藏

### 8.1 符文盤

確定使用一個符文盤，最多可同時放置 16 個符文。符文的具體效果與同類加成之後安排。

符文盤只確定容量為 16；是否採 4 × 4 排列、是否有位置差異、相鄰加成或連線規則，尚未設定，不能預設存在。

不使用符文五級成長、重複五枚升滿或滿級獎勵。重複符文作為獨立收藏／持有數量記錄，不自動合併為等級。

同種符文能否同時放置、同類加成如何計算、是否有加成上限及分類條件，待定。本版不填入符文數值、套裝門檻或具體技能。

### 8.2 取得 收藏與裝盤

- 取得的符文永久累積收藏，重複數量亦保留。
- 本次帶在身上或本次取得的符文，可隨時調整配戴。
- 過去取得、目前未攜帶的符文，需在整備房取用。
- 初始房可以安排出發時的符文搭配。
- 背包持有數與符文盤裝入數分開計算，裝盤不得憑空增加符文。
- 取用、裝盤、卸下是存取或裝備行為，不預設消耗永久收藏；是否有其他消耗規則待定。

出發可攜帶的符文總數、背包候補數、取用後收藏庫可用數及死亡後歸還方式待定。符文盤有 16 個位置，不自動代表背包也只能帶 16 個。

### 8.3 模式差異

Roguelike 的主要掉落包含符文。無雙同樣適用符文盤與收藏規則，但其符文取得途徑、掉落比例，以及是否與主副武器強化同池，待定。

尚未安排任何符文對主武器傷害、核心技能或能量的正式加成；原型的八種符文不能直接作為本版已確定的效果清單。

## 9 無雙成長與掉落

### 9.1 局內強化

主武器強化包含範圍、攻速、集氣效果等；副武器強化包含武器風格、效果與彈射物數量等。掉落效果可累加，局內可以持續變強。

同類強化的累加方式、攻速與範圍的成長曲線、彈體數量上限、傷害是否直接成長及效果相容規則待定。所有已取得強化需能顯示累積結果。

強化套用後是否仍作為背包可使用物品，尚未設定。已生效的強化不得因重複開啟介面而再次套用。

### 9.2 敵人與生存

無雙增加無敵時間、擊退距離及補血包掉落率；怪物數量成長更明顯。正式倍率分開設定，不以一個難度倍率同時代替所有規則。

一次冒險共六張圖，局內強化隨本次冒險持續累積。冒險結束後的重置範圍，以及是否另外提供無盡關卡，待定。

## 10 消耗品 補血包與金幣

### 10.1 消耗品

兩模式消耗品掉落率皆為 10%。掉落機會以何種事件計算，以及普通怪、精英、Boss 是否使用相同比例，待定。

| 行為 | 無雙 | Roguelike |
| --- | --- | --- |
| 拾取消耗品 | 立即施放一次 | 增加背包持有數 |
| 手動選擇使用時機 | 不需要 | 需要 |
| 使用後 | 不再留下可重複使用的物品 | 扣除對應持有數 |
| 功能 | 可有多種用途，清單待定 | 多樣性功能，清單待定 |

回血、護盾、回能、範圍攻擊及控場等僅是候選功能，尚未指定正式道具清單、持續時間與倍率。

### 10.2 補血包

無雙的補血包掉落率較高。補血包是否屬於消耗品 10% 掉落池、是否另行擲骰、滿血時能否拾取或收入背包，待定。

### 10.3 金幣與造型

兩模式都會掉金幣，金幣可購買 skin。商店需顯示費用、已解鎖與目前使用造型。

金幣是否同時用於副武器合成、死亡時的損失、跨冒險保留方式，以及 skin 是否僅改外觀與特效，待定。

## 11 背包與整備房

### 11.1 背包內容

角色具有背包，記錄當前圖取得的物品。背包涵蓋符文、副武器及 Roguelike 可手動使用的消耗品；金幣與已套用強化可以以持有數或取得紀錄呈現，避免把已生效效果重複當成可使用道具。

「當前圖」對應單層或整次冒險、背包容量、武器數量上限、道具堆疊上限、跨層保留與死亡處理方式待定。

### 11.2 場外收藏與當前持有

| 內容 | 保存規則 | 存取規則 |
| --- | --- | --- |
| 符文收藏 | 確定永久累積，含重複數量 | 舊符文需整備房取用 |
| 符文盤 | 同時最多 16 個 | 本次已可存取符文可隨時換裝 |
| 已取得副武器 | Roguelike 在背包保留多把 | 可切換，初始房可合成 |
| 消耗品 | Roguelike 收入背包；無雙拾取即施放 | 依模式處理 |
| 無雙強化 | 當局累加生效 | 結束時如何重置待定 |
| 金幣 造型 技能解鎖 | 跨冒險的正式保存規則待定 | 不與符文物品數混用 |

### 11.3 整備房

初始房提供出發準備與整備功能：

- 調整符文盤。
- 取用過去永久收藏的符文。
- 消耗貨幣合成副武器。
- 1-1 提供一次隨機副武器。
- 作為死亡復活位置。

六張地圖各有初始房，第 2 至第 6 張圖的初始房與前一張圖 Boss 房相鄰連接。能否隨時返回之前的整備房、主武器是否在此選擇，以及房內是否完全安全，待定。

## 12 地下城與獎勵房

### 12.1 塔式世界與六張地圖

一次冒險由六張地圖組成。每張圖包含初始房、戰鬥房、Boss 房，並依機率出現獎勵房。地圖依序生成，每次冒險的房間配置不同，整體仍形成主要往上下延伸的塔式結構。

地圖不是六張彼此獨立、位置重設的迷宮。所有地圖需要維持在同一座塔中的相對位置，跨圖後的門、位置、方向與背景高度需連續。

### 12.2 房間生成方向與遞減

往各方向生成房間的機率權重為：

| 方向 | 權重 |
| --- | --- |
| 上 | 40% |
| 下 | 30% |
| 左 | 15% |
| 右 | 15% |

上下方向合計 70%，使整體偏向縱向生長。這是生成方向的分布；「是否繼續生成房間」另有一個會隨房間數增加而遞減的機率。

- 同一張圖已生成的房間越多，繼續擴展的機率越低。
- 方向權重與繼續生成機率分開設定，不能把 40／30／15／15 當成固定房間數比例。
- 各圖必須有可從初始房抵達的 Boss 房，並保留需要的跨圖連接位置。
- 房間不得占用同一座塔中已存在的房間位置。
- 一張圖的最少／最多房間數、初始生成機率、遞減公式、不可用方向的重抽方式，以及整體塔寬限制待定。
- 機率配置需配合房間佔位與連接限制；僅有方向權重不等於已指定確切塔寬或長寬比。

### 12.3 Boss 房與下一張圖的連接

- 每張圖的 Boss 房放在該圖外側；外側判定的具體規則待定，但不預設 Boss 永遠在最上方。
- 第 1 至第 5 張圖的 Boss 房旁邊，直接接到下一張圖的初始房。
- 下一圖初始房的全塔位置，由前圖 Boss 房與連接方向決定，不重新回到共同起點。
- 下一圖以該初始房向外生成，避開所有已生成地圖的房間位置。
- 跨圖連接需有方向相反、位置對應的出入口；地圖顯示不能因進入下一圖而失去相對位置。
- 若候選 Boss 房沒有可用的相鄰空間，需要調整尚未定案的 Boss 位置或生成結果，不能建立位置不連續的出口。
- 第 6 張圖是本次冒險最後一張圖，不再接出第 7 張圖。

關卡按第 1 至第 6 張圖推進，空間上仍可往上、往下或少量橫向生長。「後續地圖」不自動等同於塔內更高的位置。跨圖後能否回到之前地圖，待定。

### 12.4 全塔位置與高度

各房間同時具有所屬地圖與全塔位置。可用第一張圖初始房作為共同原點，向上為高度增加、向下為高度降低；具體資料座標方向可不同，但遊戲中的上下關係必須一致。

例如前圖 Boss 房在全塔位置 `(x, h)`，下一圖初始房便在其一個相鄰位置，而不是重新以 `(0, 0)` 作為世界位置。地圖內的相對座標可以保留，但需要對應到全塔位置。

### 12.5 背景與世界高度

入口場景以鳥巢與樹為背景。冒險的起始環境為樹枝，向上逐漸接近樹梢、天空與雲，向下進入樹幹、草地與地下。

| 相對起始高度 | 背景環境 |
| --- | --- |
| 起始高度 | 樹枝 |
| 向上兩層 | 樹梢 |
| 再往上 | 天空與雲 |
| 往下 | 依高度逐步出現樹幹、草地、地下 |

背景依全塔高度切換，不只依目前是第幾張圖決定。跨圖時如果仍在相同高度，背景環境應延續；後續圖的初始房不一律重設為樹枝。

「向上兩層」在本版暫以全塔的房間高度層解讀，待確認是否另有較大的樓層單位。向上一層的過渡、樹幹／草地／地下的高度門檻，以及背景漸變方式待定。

### 12.6 房間通行與狀態

房間內有平台與可貼附牆面。原型為上下左右相鄰房間、人物直接穿越門口進入，進房出現在對應方位門邊，可作通行基準。正式房間尺寸、地圖揭露範圍及跨圖入口的確認方式待定。

房間需要保存本次冒險中的敵人、掉落、獎勵與已領取狀態。重新進房不能在沒有重生規則的情況下自動重建全部資源；已生成地圖也不能因再次進入而重新擲骰。

目前可玩原型採四種依種子變化的房內路線：曲折樹枝、分岔樹冠、左側層架、右側層架。平台寬度、高度間隔、左右偏移與旁支各自變化，房內幾何只生成一次，往返不重抽。主路線以普通跳可到達為基準，避免尚未解鎖進階位移就被卡住。

門、入場落點、整備巢與獎勵祭壇周圍保留空間；敵人出生點必須位於真實平台表面且彼此錯開。門採深色底、亮色框、方向箭頭與目的地名稱；畫面外門提供邊緣方向提示。掉落物用不同形狀區別類型，名稱優先顯示最靠近的一件，避免整片文字重疊。以上為本輪原型改善規則，正式房間尺寸與構圖仍可調整。

### 12.7 獎勵房

每張圖有 20% 機率出現獎勵房，以「每張圖」作為判定單位，不是每生成一間房都獨立有 20% 機率。是否出現的結果在該圖生成時確定，不能以往返房間重抽。

獎勵房採多選一：玩家在數個選項中選擇一個獎勵。選項數、種類、權重、獎勵房數量及是否有守衛待定。獎勵房的安插方式需維持該圖連通，不覆蓋初始房、Boss 房或跨圖入口。

選擇介面顯示獎勵效果、所屬模式及對目前裝備的影響。一次選擇結束後需記錄已領取狀態，離開再進入不重複發放，也不在沒有重抽機制時更換原選項。

### 12.8 推進與難度

第 1 至第 6 張圖逐步增加怪物數量、強度與種類。無雙的數量增加更多；Roguelike 的起始普通小怪以基準傷害約三刀為起點，依主武器傷害特化結算。

Boss 擊敗後開放與下一張圖初始房的通路。第六張圖完成後結算本次冒險。正式關卡命名、下關時是否補滿生命與能量，以及是否另外提供無盡玩法，待定。

## 13 敵人與 Boss

敵人也使用主武器與副武器：主武器與主武器能彈刀，主武器揮擊能擋下副武器彈體。敵人的武器具體配置與數值可以不同，但同類攻防互動需一致。

敵人所有攻擊均使用第 6.0 節的前搖、打擊期、後搖三階段，每階段時間可獨立控制且各有動畫，讓玩家辨識可拼刀、可擋彈、需閃避及可反擊的時機。

### 13.1 敵人與 Boss（目前可玩原型）

一般敵人有苔甲衛士、果實投手、薄暮獵蛾、古枝守衛四種，使用對應已交付圖集。Boss 則依全塔生態選擇逐霆隼王、綾冠螳后、織巢蛛母、琥珀鍬皇、露冠蟾王、盲根掘王；各自有專屬角色與攻擊特效，不再六圖共用樹心巨靈。

完整攻擊參數、三階段時間、移動組合及素材對照見 [boss-combat-design.md](boss-combat-design.md)。每種 Boss 至少兩種攻擊模板與兩種移動方式；身體碰撞面積是標準 34×42 敵人的 8 倍，保留各物種比例。Boss 房中央留空，兩側通道以普通跳躍可抵達上方出口。

一般怪基準生命為 3／3／3／10；每往後一圖加 0.5。Boss 使用自身基準生命，再加章節索引 ×10。所有活敵身體接觸傷害為 1、擊退 0.8 身位，搭配無敵幀與受傷回饋。

### 13.2 共用攻擊與移動庫

攻擊庫包括斬擊、飛行斬擊、直線子彈、拋物線子彈、固定陷阱。體積、距離、速度、穿透、數量、曲線、陷阱有效傷害次數與傷害均有獨立參數；共用前搖／打擊／後搖時鐘。前搖鎖定方向／陷阱位置，打擊期開近戰判定或生成獨立攻擊，後搖提供反擊窗口，完整收招後再等待招式冷卻。

移動方式為左右、跳躍、懸浮、移動漂浮、衝刺；往哪裡走的邏輯獨立配置為主動靠近或自主漫遊。普通敵人也使用相同庫：甲蟲左右靠近、投手左右漫遊、獵蛾懸浮／漂浮、守衛左右／衝刺。地面敵人保留平台邊緣限制，飛行敵人避免進入平台；尚非完整跨平台尋路。

出招依列表循環挑選可觸及玩家的招式；近戰另檢查垂直高度，遠程最大活動距離為 900。攻擊時減速，移動衝刺的預備與位移期間不開始新攻擊。已出手彈體有路徑掃掠判定；穿透彈對同一目標只命中一次。傷害陷阱有位置預警、啟動延遲、有效命中上限與同目標間隔，玩家無敵期間不消耗次數。

### 13.3 出生與活動範圍

初始房與獎勵房無敵人。一般戰鬥房每個有安全出生空間的平台獨立擲機率：Roguelike 55%、無雙 85%，含地面及上層。Roguelike 每個選中平台 1 隻、無雙 2 隻，第 4 圖起各增加 1 隻，仍受安全候選點數限制。全房最低補至 3 隻，前三隻分別為近戰／投手／飛行；其餘依生態權重抽出四種一般／精英角色。Boss 房 1 隻 Boss，未設增援波次。

距離玩家大於 900 且未出招的敵人暫停追蹤與出招；已開始的攻擊照常結束。尚未實作兵種協作、增援排程、完整畫面外出招規則、Boss 血量階段切換及素材設計文件中的所有進階彈體行為，不能將設計構想視為已完成內容。

## 14 受傷 死亡與復活

角色生命耗盡時死亡，可以在初始房復活一次。

以下細節待定：

- 一次復活的範圍是整次冒險、每章或每層。
- 復活回到 1-1 初始房，或目前關卡的初始房。
- 復活時的生命、能量、短暫保護及敵人狀態。
- 背包、金幣、無雙強化與已裝符文的保留或損失。
- 無法再次復活時的結算、重開與永久收藏保留流程。

復活及重新進入初始房不得在沒有重發規則的情況下，重複產生 1-1 免費副武器或已領取獎勵。

## 15 命中特效與掉落光效

所有有效命中與被擊中都要有對應特效，涵蓋玩家、普通敵人、精英與 Boss。

| 事件 | 必須呈現的結果 |
| --- | --- |
| 主武器普通命中 | 接觸點特效與目標受擊回饋 |

## 17 房間生態、身體接觸及介面更新

- 每房生態依全塔座標高度決定：≥+3 天空、+2 樹梢、0～+1 樹枝、−1 樹幹、−2 草地、≤−3 地下。切換背景與生態抽怪權重；跨圖延續高度。六區插畫已套用，未拆為可獨立動態的視差層。

- 所有活著的敵人預設啟用身體碰撞傷害，不要求敵人正在出刀。接觸扣 1 生命，水平擊退 0.8 個玩家身位（34×0.8＝27.2 遊戲單位，0.12 秒完成）。擊退期間不被一般移動摩擦立即消除；實際移動受房間邊界限制。

## 18 金幣物理（原型 v0.4）
