# v0.21 地圖、移動容錯與生態地形

## 地圖與關卡

按住 Tab 改為大型區域圖：放大目前關卡，固定48×30px房間卡、清楚的門連線、目前房間雙框／箭頭、整備／首領／商人／獎勵／溫泉圖例；右側列出六關的探索進度。橫向與縱向間距各自計算，較高的關卡不會把字卡壓成小點。檢視時暫停遊戲，放開即返回，並隱藏可能遮到地圖的左上HUD。

預設每關9～11間，六關連通。主幹向上生長，支路深度受控；Boss是本關從Start出發經可通行門計算的**唯一最遠房間**，位於外緣。本關從Boss一側進入，擊敗後從另一側直接進入下一關Start；Boss沒有上下門。可選環路只連接相近深度的節點，避免讓Boss變成近路。

功能房仍採17×11格內裝，現在宏觀世界的對應行／列也同步尺寸，修正內裝尺寸與房間網格各自縮放造成的門位不一致。RD房數參數上限改為12；0使用新的9～11隨機預設。已生成的冒險不搬動房間，開始新冒險套用拓樸。

必要跳台仍依各房地形補設。隨機廣場跳台使用1、2、3格寬，只有大於5×5的空洞會放；會避開必要路線上下48px的落點干擾帶。

## 操作手感查核

專案使用Godot 4／GDScript。以下機制不依賴Unity也可實作。

| 機制 | 目前狀態 |
|---|---|
| 程式控制落地微縮放 | 原有，0.09秒、約8%，腳點不變 |
| Boss傾斜／拉伸、怪物微幅動態 | 原有 |
| 命中頓幀 | 原有，主武器3／4／5幀；物理、動畫與戰鬥粒子一起停止 |
| 震動、命中火花、敵人白閃 | 原有，敵人輪廓白閃1/60秒 |
| 主角完整輪廓白閃 | 本版新增獨立材質層，不把武器與UI一起變白 |
| 土撥鼠時間 | 本版新增0.10秒，先判定地面寬限再判定二段跳 |
| 跳躍輸入預緩衝 | 本版新增0.12秒；著地／可行動後消耗一次，放開過的短按仍是小跳 |
| 拐角修正 | 本版新增最多4px，僅主角向上碰撞時啟用；全身與路徑須清空，不能穿過完整天花板 |
| 攻擊預緩衝 | 維持關閉，符合「無法出擊的點擊直接無視」的既有要求 |

角色真正受擊仍有簡短受擊姿勢；新增的白閃與頓幀不使用冗長逐格退後動畫。移動碰撞與美術微縮放彼此分離。

## 屍體與掉落

普通怪、菁英、飛行怪和Boss死亡後保留各自物種的完整身體，翻倒並用重力、實體地形和平台落地。屍體沒有消散計時、透明淡出或數量淘汰；在本次冒險內，離房返回、角色死亡回整備點都會保留。另開新冒險才重建世界。屍體不阻擋活著的角色。

停止擊殺時的虛化身體／羽毛消散路徑；普通命中的火花與短促回饋保留。落地屍體休眠，繪製採保留指令，只有仍在下落時才更新碰撞與繪製資料。

所有掉落種類現在都會隨機向上噴發，再受重力與地形碰撞影響。金幣仍一枚一實體，可互撞、彈跳、滾動；符文、副武器、消耗品、補血與強化不再生成時直接吸到地面，也沒有額外浮動正弦位移。掉落有0.35秒拾取寬限，保留可見的噴發過程。金幣碰撞半徑7px／圖像半徑8px，其餘半徑18px／圖像半徑22px。

## 新美術與圖層

以`module_branch_medium.png`的厚實手繪輪廓、苔草、垂根與岩木結構為參考，使用內建image_gen新繪六張透明原圖，保留原始1254×1254像素及alpha，沒有程式重繪或重新著色PNG。

- `assets/v21/terrain-underground.png`、`terrain-trunk.png`、`terrain-sky.png`
- `assets/v21/props-underground.png`、`props-trunk.png`、`props-sky.png`
- 完整提示詞：`assets/v21/prompts.json`
- 精確裁切、腳點、縮放參考與逐幀雜湊：`assets/v21/atlas-metadata.json`

地底維持土色岩根、樹幹是綠色苔木、天空是藍色風化枝石。每區地形圖集包含內部材質、上下邊、側牆、外L角／內凹角、單格／直柱端點、三種長度跳台及邊緣裝飾。任意單格、雙格、三格、多格、水平、垂直和L形實體以同一套暴露邊／角點合成，不對合併矩形的內部接縫重複畫外框。

材質使用共用世界座標取樣，鏡像變更以**六格**為一個區段；不逐格或每兩格交替翻轉。來源PNG不是天然保證無縫的瓦片，接合由共用取樣和實體聯集的邊界判定處理。孤立單格使用未翻轉的獨立方塊圖；短跳台使用獨立1／2／3格原畫，長橋保留作者畫出的左右端點。

每區另有3種大型、3種中型景物、6種小型可砍物件及6種小裝飾。18種可砍物件各有完整／受砍／碎裂／殘骸四個不同姿態；每幀腳點獨立校準、使用同一縮放基準。新增素材可在RD美術室的「地形連接模組」「新生態物件與破壞」「新生態中景與裝飾」搜尋檢視。

中景物件使用獨立模糊材質、低飽和半透明繪製，沒有碰撞。互動地形、怪物、主角仍在前景；前前景小石、草叢、垂根、牆面突起則以最高的世界裝飾層蓋在角色上方，HUD與地圖仍在其上。

## 驗證

新增100個種子的約6,000房拓樸檢查，確認房數、唯一最遠Boss、左右門及下一關串接；實際控制器測試涵蓋離地寬限、著地預按／逾時、短按跳高、拐角清空、全部掉落種類與屍體跨房／角色死亡保存。沿用普通跳躍／下落的雙向門可達測試。

18組實際Web資源包測試全數通過；10個種子344個戰鬥房、706個門完成普通跳躍／下落雙向可達驗證。導航平台回歸使用同一批房間的舊雙梯配置作為比較基線，避免更改房間尺寸後比較不同樣本的絕對占比。新增資源加入Web匯出與RD索引。瀏覽器GPU畫面、聲音與FPS仍需支援WebGL 2的環境實測；無畫面控制器測試不代表已完成視覺手感驗收。來源切片的細節限制另見`v21-art-layout.md`。
