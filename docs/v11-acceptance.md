# v0.11 背包與操作更新

| 項目 | 行為 |
| --- | --- |
| 小地圖 | 預設隱藏；按住Tab顯示、放開隱藏；不開選單、不暫停。視窗失焦或開背包時自動隱藏；重新綁定地圖鍵後沿用同一按住規則 |
| 靜音 | 畫面上方直接切換，立即靜音整個音效匯流排，涵蓋音樂、腳步、戰鬥、雨聲；設定永久保存。按鈕不搶走Space的遊戲操作 |
| 副武器HUD | 左上獨立一行顯示目前名稱、專屬插圖及Q切換；實際鍵位重綁後提示同步更新；沒有武器時顯示尚未裝備 |
| 雙頁背包 | 武器與補給／符文刻印兩頁。左側顯示目前裝備，右側列出可換／可用項目，右側長清單獨立捲動 |
| 物品說明 | 鍵盤焦點或滑鼠移入時，同步在中下方固定區域顯示插圖、名稱、效果；符文另顯示該種相鄰連線加成 |
| 符文槽 | 3個大型金色刻印、16個4×4小型紫色槽。大槽寬106、小槽寬48；不同鑲邊與插圖。按空槽再選右側符文可指定位置，卸下時不移動其餘符文 |
| 相鄰連線 | 上下左右相鄰的同種小符文，各條邊亮起紫白柔光；不連對角、不跨行。每條邊讓該種類小符文的總效果+1%，例如4個風羽構成方形共有4條邊，效果為4×6%×1.04。大符文無連線加成。整數投射物加成的小數部分轉成額外一發機率 |
| 家中庫存 | 只在整備房顯示可取用的武器、消耗品、符文。取出武器會直接裝備；取出符文一枚並裝入空槽；補給取出一份後立即使用。副武器可在寄送站送回家，JSON保存完整數值及色彩 |
| 空中副武器 | 可出招且能量足夠時，按下按鍵同一事件即跳過前搖進入有效期，立即發射／啟動近戰判定；消耗1能量並保留後搖。地面維持武器原本前後搖，忙碌時不排隊 |

新圖：`assets/inventory_v11/runes.png`（20種獨立符文）與`items.png`（11副武器、5補給），皆為內建imagegen產生的原始透明PNG。程式只選取圖集區域，沒有程序修圖。來源、格位和提示摘要見同目錄`manifest.json`。

Prompt set：soft hand-painted gouache forest item atlases; twenty uniquely engraved purple small/golden greater rune jewels, plus eleven distinct organic wooden/feather/crystal weapons and five supplies, genuine alpha transparency, generous sprite separation, no labels or UI baked in.

測試：`test_v11.gd`涵蓋實際Tab事件、失焦、靜音與保存、Q切換HUD、11種空中副武器按下同步出招、相鄰拓撲與計算、空槽定位、滑鼠/鍵盤焦點說明、4×4方向移動、所有圖集引用、19格版面邊界，以及家中物品逐一取用和武器JSON往返。

全套回歸與實際Web PCK回歸另由`verify.py`／`build_web.py`執行。版面邊界以Godot實際Control位置驗證；遠端瀏覽器缺WebGL2，尚未完成瀏覽器畫面、混音及手感的人工驗收。
