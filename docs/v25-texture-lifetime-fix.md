# v0.25：貼圖生命週期、裝備選單與投射物辨識度修正

## 原因

v0.24 的18張邊緣裝飾使用函式內的暫時 `load()` 結果繪製。保留繪製指令的CanvasItem僅保存紋理RID；函式返回後，沒有其他擁有者持有Texture2D，資源就被釋放，已保留的指令因而會畫成白色輪廓／白塊。

先前的匯出測試只確認素材存在、可載入及行為正確，沒有檢查繪製完成後的貼圖存活時間，漏掉這項回歸。

## 修正

- 為三生態共18張邊緣裝飾建立持續持有Texture2D的共享快取。
- 過幀、保留畫面與切換房間時繼續持有貼圖，避免繪製指令引用已釋放的資源。
- 保留原貼圖、像素密度、地形與碰撞資料，不增加逐幀重畫來掩蓋問題。
- 遊戲外殼與畫面版本更新為v0.25。

## 驗證

- 修正前，同一個實際CanvasItem `_draw()` 探針顯示 `ResourceLoader.has_cached(path) == false`；修正後為 `true`。
- 新增 `test_texture_lifetime_v25.gd`，讓三生態18張裝飾實際經過CanvasItem繪製；跨4幀後檢查存活，再移除房間繪製節點並跨4幀確認資源仍保留。繪製只執行一次，沒有用不斷重畫代替修正。
- 該測試在舊程式失敗，在修正後通過，並加入Web匯出的實際PCK回歸檢查。
- 相鄰地圖與v0.24功能回歸通過。原始碼整批檢查39組通過，粒子預算恢復為原來5個後，相鄰4組補測全部通過；最終Web實際PCK回歸24/24組及資源拆檔雜湊檢查通過。
- 測試環境的遠端瀏覽器先前缺少WebGL2，因此本次不聲稱已完成實際GPU畫面或FPS驗證；此次修正以可重現的資源釋放／存活檢查為依據。

重新整理並重新載入遊戲後生效；本次不需要重開新冒險。


## E裝備選單

- 移除符文頁混入的舊版「武器與補給／符文刻印」兩頁籤。所有裝備頁只有同一組四頁籤。
- 可見排列從左到右為「消耗品／附武器／主武器／符文」，與主武器頁按左一次到附武器、左兩次到消耗品、右一次到符文的順序一致。
- 初始焦點在目前頁籤。左右換頁；↓或X進入清單，↑在清單頂端回頁籤；E或Esc關閉。
- 清單上下逐列移動，不會跳到其他頁籤、關閉鈕或上一頁的控制項。確認裝備或使用物品後保留可用游標位置。
- 符文盤內四方向操作格子，右側進入實際符文清單；選擇空槽後裝備符文，游標與目標槽保持一致。
- 空附武器頁不再錯用主武器當預覽；空消耗品頁不再顯示未持有的補血物品。
- 選單開啟時擋住主武器數字快捷鍵、Q及K，避免遊戲快捷鍵暗中改裝備或打開其他面板。
- 新增實際按鍵與焦點流程測試，涵蓋換頁、清單邊界、確認後保留游標、空背包、符文4×4導航及E關閉。

## 投射物與軌跡

- 玩家投射物與敵方投射物提高視覺尺寸下限；長形原畫依最短邊與最長邊共同定比例，避免箭矢被壓成幾個像素。
- 玩家原畫加入深色輪廓，兩方均補淡光暈，與不同背景保持對比。
- 每顆實體投射物保留最多32個軌跡點、約0.45秒歷史，使用深色外緣、彩色主體與亮色中心繪製連續拖尾。
- 精簡特效也會保留這條核心軌跡，不受24個粒子發射器上限影響；因此無雙齊射時其他子彈也仍可辨認。
- 補強粒子亮度、尺寸及0.48秒存續時間。投射物的傷害、速度、射程及實際碰撞數值保持原設定。
- 新增九種原畫顯示尺寸、曲線軌跡點上限與時間淘汰、實際CanvasItem軌跡繪製以及物理數值保持不變的測試。
