# v0.38 戰鬥視覺與死亡流程

## 完成內容

- 門口改回半透明抗鋸齒圓點，密度提高；沒有線段吸入或漸層光板。
- 大型命中為單張新手繪細長月牙；短暫顯示、角度隨機，長軸固定為畫面寬度三分之一。
- 另一命中效果保留三張碎羽姿勢，依攻擊反方向從敵人目前姿勢的可見輪廓之外噴出；考慮朝向、菁英尺寸及非對稱貼圖。
- 雷射使用八張獨立連續光束貼圖，不沿線重複畫武器；支援任意方向，寬度符文同時改變貼圖和判定。
- 二段跳朝下噴出實體羽毛貼圖粒子，以遊戲世界尺寸決定大小；保留小型拍翅風貼圖。
- 移除主角常駐主武器覆蓋圖；攻擊本體與刀光動畫保留。
- 普通與菁英怪恢復一點接觸傷害；玩家無敵時間仍避免連續扣血。單C可受傷、雙C前搖與打擊期保護。
- 第一次倒下重傷，第二次死亡落地變羽毛，選一枚符文返回安全屋。其餘背包、金幣與成長可回收；背包快照獨立，選走的符文不重複計算。
- 怪物重生、未擊敗Boss重置；已完成Boss保留。安全屋屍體保留，重生戰鬥房清除舊屍體。倉庫不變。
- 無雙滿16把時，取不下的武器留在羽毛；重試不會重複領錢或成長。肉鴿同武器合併至+8。
- Memory & Architecture Decision Sync 已可用，專案另有規則檔與啟動前讀取要求。

## 驗證方式

`tests/test_combat_v38.gd` 驗證接觸傷害、C/CC、實際二段跳粒子、怪物輪廓外噴發、八幀雷射、牆面阻擋、死亡帶符文、倉庫、完整掉包取回、無雙溢出與肉鴿合併。既有v08、v20、v30測試已改為使用者選定的羽毛返程流程。

`tests/fixtures/capture_combat_v38.gd` 在1920×1080、Godot原生OpenGL相容模式拍攝18張畫面，檢查三幀命中、八幀雷射、三種門口色彩、二段跳、待機主角、死亡羽毛、死亡符文格與返程安全屋。

新素材、原始圖及生成提示詞保留於 `assets/v38/`；使用內建 image_gen，正式貼圖為 `effects/clean-crescent.webp`、`effects/laser-beam.webp`。原始圖與提示詞不會打包進遊戲。

此驗證涵蓋自動測試與原生1080p畫面，不等同六圖完整人工通關或所有瀏覽器實機測試。
