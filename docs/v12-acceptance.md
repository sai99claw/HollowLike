# v0.12 場景、試用、溫泉與效能

| 需求 | 行為 |
| --- | --- |
| 門邊不要文字 | 移除名稱牌、靠近提示、方向字元與畫面邊緣的文字指標；目的地門光顏色和鎖定圖形保留 |
| 武器／符文缺圖 | 世界掉落物改用與背包相同的新圖集解析器，涵蓋11武器、20符文與5補給。施放副武器時手中也顯示對應武器插圖 |
| 商人房 | 固定1500×843.75的16:9房間，自動取景，無捲動。新繪木桌、遮棚、羽毛招牌、試打假人；三張桌子各擺兩件商品。每區有固定精選配置，不依房間種子亂抽；已買商品重返不補貨 |
| 拿起來試用 | 走近桌上商品按互動／攻擊確認，再選拿起試用。武器或符文暫時裝上；大符文槽滿時可暫借替換末槽。試用能量會補充，有買下／歸還按鈕；假人不會死亡，所有副武器都能測試命中數值 |
| 滿意再購買 | 試用不收錢，購買才扣隨身金幣。武器會成為正式裝備；符文加入行囊。每件只買一次、金幣不足不能買。借用狀態在離房、開背包／符文盤、重新開始或死亡前還原，不會帶走借品或永久獲取試用回血／能量 |
| 溫泉房 | 固定單畫面，分層後石沿、水面、前石沿、蒸氣；池底比岸邊低28，水面在岸上12。人物能走下淺階入水，身體受水色及前石沿遮擋，走動與進出產生有上限的波紋／水花 |
| 水中互動 | 入水移速×0.55、下落速度受水阻；可走上淺階離池，也可跳出。只有身體確實入水時才回血每秒1格、回能每秒2格；浮在水面上方不算浸泡 |
| 房間最小一畫面 | 普通房視野縮放不超出房間實體邊界；商人和溫泉恰好完整放入一個畫面。所有通路方向組合都保留普通跳躍可達路線 |
| 集氣傷害 | 打擊期固定1.5秒，逐目標紀錄命中次數和下次可命中的時間，最多3次、間隔至少0.5秒。晚進入範圍也不能因跨時間格而連續受到兩次傷害。普通攻擊仍維持原本單次去重 |

效能：快捷列只在物品數量改變時重建；生命／能量格重用StyleBox，未改變時跳過配置；符文連線不再空轉重繪；預設精簡特效略過大面積中近景模糊，野生物改為9次固定權重取樣，取代49次取樣與每像素exp；場外物件跳過繪製。維持前景黑白羽毛、雨幕、門光和主要命中效果。

同一環境的headless CPU微測試：200次未變更快捷列更新，首顆按鈕由200個不同實例降為1個；CPU量測由1,729,798微秒降至734微秒。這僅代表此UI更新路徑，不能換算為玩家瀏覽器FPS。數據保存於performance-v12.json。

驗證：全套21組回歸通過；最後變更重跑v12、v08；實際Web PCK再跑7組，並驗證拆檔大小與SHA256。v12包含32種安全房通路組合、固定商品／三桌分配、19格UI原有契約、借用與購買、不死假人上11種副武器、進池和走出淺階、入水回血條件、全房最小視野，以及三種集氣各3次命中／晚進入目標的0.5秒間隔。

美術：assets/sanctuary_v12/pool.png、shop.png皆由內建imagegen生成，保留原始透明PNG，程式只取圖集區域。提示摘要和素材區域見同目錄manifest.json：分層苔石溫泉的後沿／水面／前沿／蒸氣；貓頭鷹小舖的空桌／遮棚／羽毛招牌／軟墊假人，柔和手繪森林風格、不烘焙文字或商品。

驗證限制：目前遠端瀏覽器缺WebGL2，尚未完成瀏覽器畫面、混音與手感驗收，也不能證實玩家裝置上的FPS提升幅度。已驗證程式行為、物理路徑、素材載入、CPU重建量與匯出包。
