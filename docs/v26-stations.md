# v0.26：鍛造、重鑄與倉庫

- 移除整備房武器架。免費附武器仍可在原有掉落位置按上領取，主武器由E面板切換。
- 藍圖鍛造改為九種附武器圖示格。未取得藍圖用灰階顯示且可預覽，旁側顯示大型武器圖、效果、解鎖條件與合成金幣需求。費用30金幣，優先扣隨身再扣家中；無雙16把與Roguelike重複+8上限均於扣款前檢查。
- 符文重鑄左側約2/3為操作區、右側約1/3為三欄符文格。可選隨身與家中所有小／大符文，點入三槽，點槽退回，恰好3枚才可合成。介面解釋隨機結果與材料消耗順序。未裝備隨身材料優先，其次家中，必要時才卸下裝備材料。結果不同於所有材料種類，有空槽會自動裝備。
- 寄送站改為倉庫，支援全部、小符文、大符文、附武器、消耗品與金幣六種檢視。右側選物件，左側大圖與說明；可取出一件、取出金幣、存入金幣／附武器／消耗品。
- 「一鍵儲存未使用符文」只搬移未裝備的份數；同名多枚及大符文皆保留已裝備份數與原位置。消耗品取出不自動使用。武器達上限時庫存不減少。
- 三站使用獨立透明手繪哥德美術，詳見 `v26-station-art.md`。符文與武器大圖沿用同一套已交付美術。貼圖持續持有並以可見邊界貼齊地面。
- 新站點使用獨立方向鍵焦點範圍，邊界停止；重建後維持操作焦點。阻止開啟選單時主武器切換鍵和技能快捷鍵穿透。

## 驗證

- 新增 `test_stations_v26.gd`，驗證實際站點移除、9藍圖、灰階鎖定、目前預覽合成、3槽增減、隨身／家中混合材料、重鑄原子扣除、分類、消耗品取出與庫存上限保護、畫面寬度與方向鍵邊界。
- 更新舊站點測試以符合移除武器架與倉庫改名；保留戰鬥、移動與舊美術資源驗證。
- Web發布包執行25組回歸並檢查分塊雜湊。瀏覽器畫面實測結果另列最終交付說明。

最終結果：發布包25/25組回歸通過，PCK與WASM分塊大小和SHA-256均通過。三站介面在1280×720的內容高度分別442／440／488px，皆低於542px可用高度。遠端預覽瀏覽器回報缺少WebGL2及Secure Context，故未能實測WebGL畫面、灰階shader與滑鼠畫面操作；未變更瀏覽器安全設定。

封裝容量修正：清除恢復工作目錄時留下的中斷分塊暫存檔；新增發布輸出總容量檢查。三張站點原圖保留1254px，執行時以512px無損匯入，維持世界顯示所需的2倍以上來源像素密度，並依匯入尺寸換算貼地裁切範圍。
