# v0.41 無雙夢境

這一版只改變 `musou` 模式，名稱統一為「無雙夢境」。Roguelike 的攻擊時鐘、無敵時間、人口與死亡規則保留。

## 戰鬥與怪物

所有攻擊時鐘的前搖、後搖歸零，包含玩家主攻擊、集氣釋放、附武器、雙 C、炸彈道具與敵人的攻擊。按住集氣所需時間與有效打擊期保留；敵人獨立出招冷卻仍保留，避免取消前後搖造成每幀出招。附武器整批齊射打擊期為 0.16 秒，選取哪把武器不影響全批節奏。玩家每次受傷的無敵時間固定 2 秒。

以本來的生成計畫為基礎，小怪與菁英數量向上取整為原數量 × `1.4 × 1.1^stage_index`，第一關為 ×1.4、第六關約 ×2.255。Boss 本體保持一隻，增加菁英守衛。新增位置遵守平台、實體碰撞、門口 180px 安全範圍與角色間最小間距；極小房間以可安全容納的空間為限。固定種子產生相同結果。

## 重傷爆發

第一次生命歸零立即在原位進入既有重傷狀態並回復重傷生命上限，不走擊飛、落地、起身動畫，也不給玩家額外擊退速度。保留重傷的生命／能量上限與移動懲罰。爆發能量波與螢幕震動推開房內所有存活敵人，包含畫面外的敵人與 Boss；不對假人施加位移。這次推開不造成傷害、不回充能量。

攻擊力 ×2 持續 120 個有效遊戲秒，以共用的實際傷害入口作用於近戰、彈體、光束、連鎖、爆炸、陷阱、持續傷害及被動攻擊，避免重複乘算；專用羽毛能量粒子與 HUD 倒數顯示作用時間。選單、小地圖、命中停頓、死亡動畫不倒數。期間回安全屋治療不會提前移除尚未到期的強化。第二次倒下仍死亡、選符文返程與回收掉包；返程及新冒險清空此強化。

## 無雙能量與自動斬擊

新增 20 格 HUD。各種攻擊每次有效傷害命中敵人，或摧毀一個敵方陷阱，增加 1 格；訓練假人與場景物件不回充。多目標、多彈體與持續傷害依實際有效命中次數累積。溢出保留，滿格排入自動施放，不占用玩家攻擊時鐘或消耗一般附武器能量。

擴散本體沿用 `feather_charge` 舊羽毛刀集氣斬效與 `pigeon_feather_charge` 角色動畫，圍繞主角當前位置向外擴散，單次波動對每名敵人至多命中一次；另發射 8 道徑向飛行斬擊，沿用現有月翎刀動畫與地形碰撞。飛行距離以 `640 / camera_zoom` 世界像素計算，始終是 1280 邏輯畫面寬的一半。

**未指定數值的實作預設**：每次有效命中 +1；擴散本體半徑 180/zoom、持續 0.6 秒、傷害一般攻擊 ×2；8 道飛行斬擊各為一般攻擊傷害。重傷倍率再於傷害入口作用一次。自動斬擊本體與飛行斬擊不回充自己的能量，避免無限連鎖。跨房保留格數、待施放次數與強化時間，清除上一房的波動和彈體；新冒險、死後返程清空。

## 夢境表現與效能

獨立暗角強度為 0.48（原本聚焦暗角為 0.22）；中景 18、前景 12 個半透明環狀泡泡持續上飄。泡泡貼圖由一次建立的漸層資源產生，不新增大圖集。強化期間有 28 粒羽毛能量光點。離開夢境會停用粒子的處理與顯示；暫停時凍結。保留 v40 的 Web 720p 上限、畫面外裁切與貼圖快取。

中文字型沿用 Noto Sans CJK TC，重新建立保留所有既有字形的子集，補入「夢」等新介面用字；OFL 授權保留。

## 驗證

`tests/test_musou_dream_v41.gd` 驗證 19/20 格邊界與多次溢出、全六關人口倍率、固定種子、Boss 唯一性、玩家／敵人零前後搖、近戰與彈體／雷射／連鎖／爆炸／持續傷害回充、自動發射與半畫面射程、不自我回充、重傷不移位與全房擊退、雙倍傷害及期限、暫停／命中停頓、20 格 HUD、泡泡／暗角／光環、第二次死亡，以及 Roguelike 隔離與新字形。

完整發布測試由 `scripts/build_web.py` 對實際匯出的 PCK 執行，另檢查分片雜湊與主機容量。瀏覽器環境缺少 WebGL 2，因此自動測試不代表已完成實機動畫、手感或 FPS 驗收。
