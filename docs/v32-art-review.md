# v0.32 美術審查與調整

依使用者提供的《The Secret Behind Hollow Knight’s Art Style!》逐字稿逐項對照現有素材與實際繪製流程。文章為講者的美術分析，以下也包含對本專案的設計判斷。

| 景層 | 審查結果 | 本版修正 |
| --- | --- | --- |
| 後景 | 3:2原畫被拉成4:3，細碎枝葉與建築反差會搶地形 | 還原比例；依天空藍／樹幹綠／地下琥珀套用遠景霧色，降低對比與飽和，柔化細節 |
| 中景 | 原本深色乘算加低透明度，使完整建築只剩黑影；九個位置反覆放兩種物件 | 恢復可辨的完整輪廓，最多六件、分區且保持距離；比後景更清楚、比可玩層更柔和；保持來源2px／世界1px |
| 前景（人物後方） | 高裝飾量太多，與角色輪廓互相競爭 | 降低貼邊裝飾密度，統一較沉穩色值；高於角色的素材留在人物後面，維持貼合內嵌10px |
| 前前景（人物前方） | 小裝飾與大羽毛會一起搶視線 | 小件維持清楚暗輪廓、拉開間距；最近羽毛降低不透明度；維持只有低於角色的貼邊件能放前方 |
| 遊戲焦點與微粒 | 全畫面暗角48%壓暗遠處可玩地形；地下卻使用紫色微粒 | 暗角降至22%，地下微粒調回琥珀金，保留必要提示的色彩地位 |

採用原則：輪廓先於紋理、清晰度隨距離遞減、分離明暗群組、保留生態單一主色、裝飾留白與視差深度。金屬細節與高光保留在武器等焦點素材。沒有將所有景層一律模糊，也沒有把完整背景框蓋到戰鬥區。

本次判斷：現有三生態原畫和完整中景仍可用，主要問題在呈現與配置，先修正這些。中景目前各生態只有兩款原畫，未來補圖應優先增加真正不同的大型輪廓，不能靠放大舊小圖冒充大型物件。

## 遊戲規則

- 投射物最長主體直徑＝人物標準高度1/4（50.9375／4＝12.734375世界像素）；每枚體積符文仍增加5%。
- 同高度相交／相接的跳台合為一段再拆碰撞模組；美術整段只畫兩個外端頭，移除接縫重疊端頭。
- 準備房、商人房、獎勵房從塔拓撲開始限制左右門，互通與小地圖座標一致；準備房保留可達的二樓站點，商人／獎勵房移除通頂雙梯。
- 房間拓撲改動需重新開始一局。倉庫與共用意見資料保留。

## 驗證

- 同一份最終Web資源包的32組回歸均通過。素材總表測試首次超過60秒時限，保留相同資源包後以180秒時限重跑通過；其餘31組於完整批次通過。驗證器的每組上限調整為180秒，測試內容與斷言未刪減。
- 新增測試覆蓋336個房間的非重疊跳台、左右門拓撲、清楚的進房出生點，以及1/4投射物、3:2背景與景層參數。另有實際控制器的雙向出口檢查、商人／溫泉／準備房互動與死亡重開回歸。
- 角色移動入池、涉水阻力與回血均通過；修正新拓撲使下方通道穿過池底的既有幾何缺陷。怪量比較測試改為選實際戰鬥房，避免把固定房號誤當戰鬥房。
- 意見後端、觸控Node測試、Web分片SHA-256與容量檢查通過。靜態匯出267,474,716 bytes。
- 已逐張檢視三生態後景、中景及近景素材，並對照實際繪製程式。雲端瀏覽器仍缺少WebGL2；本版未完成實際瀏覽器遊戲畫面的視覺驗收，不將程式回歸描述成完整試玩。
